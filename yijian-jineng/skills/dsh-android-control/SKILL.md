# Android 桥接
设备侧初始化由scripts/bootstrap.py执行，会核对/推送官方包的JAR并启动服务；这不是纯只读操作。当前两台手机此前已接通，不重复初始化。真实账号测试按用户要求在开发交付后进行。
使用 scripts/phone.py。这是基础控制桥接，不是平台发布器；没有安装、登录、删除或发布命令。命令见 [手机调用](references/commands.md)。

先 devices。unauthorized 时让用户在手机授权；offline 时检查连接。涉及设备操作必须明确 --serial，不能默认第一台。两台设备分别验证。应用实例登记前读取 info/apps/users，核对机型、系统和 App 版本；不猜包名或分身用户 ID。

先 claim 对应任务的设备，再启动实例或传素材。普通 App 可 open；系统用户启动依机型实测；manual-clone 用实际分身入口，不能把原版启动当成分身已打开。启动后截图核对个人主页账号，错误即停止。
push 只把素材送入主用户共享存储，分身或工作资料未必可见；必须在目标实例里查看素材。传输成功不能算上传成功。

手机界面可选 scripts/ui.py，依赖另行确认安装的 uiautomator2。它支持观察、精确元素点击、中文输入及经台账确认的提交，调用见 references/commands.md；尚未真机验证时不得声称可用。uiautomator2 连接可能初始化设备侧组件，先确认部署范围。也可使用宿主实际提供且已授权的手机/视觉工具。没有工具时停在文件传输。

不自动清除数据、退出账号、安装多开软件。安装选定软件前列出官方来源、版本、目标设备、组件和权限，按用户约定确认；登录由用户完成。
