# 框架逻辑迁移与生成
按需读[脚本框架](../product-market-marketing/references/short-video-script-framework.md)、[种草框架](../product-market-marketing/references/seeding-copywriting-framework.md)。
读取框架库、产品事实与账号定位。将原作品的钩子功能、冲突、推进、证据、转折、结束和节奏逐项映射到新素材，而非替换几个名词。
先给框架映射表和逻辑说明，再写新标题、正文/脚本、分镜、字幕、封面和素材需求。事实、经历、销量及证据只能来自自己的材料；不仿造作者身份或声称自己经历了原作者事件。
差异检查覆盖主题切入、事实素材、段落表达、画面、配乐授权、账号场景。借鉴结构可行，复制原图、逐句改词、复用他人声音需另有权限。
保存原创母稿与各平台适配版，交account-content-factory和desktop-media-production制作。
