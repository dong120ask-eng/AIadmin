# AI可引用性评分与优化

## 基本信息
- **英文原名**: geo-citability
- **所属项目**: geo-seo-claude
- **核心能力**: 分析网页内容以确定AI系统（ChatGPT、Claude、Perplexity、Gemini）引用或引用页面内容的可能性。提供可引用性评分（0-100）及具体重写建议。

## 核心洞察

AI语言模型引用满足特定结构标准的段落。普林斯顿、佐治亚理工和IIT德里（2024年）的研究发现，GEO优化内容在AI生成响应中的可见度提高30-115%。关键发现：AI系统优先提取和引用满足以下条件的段落——**134-167词长**、**自包含**（无需周围上下文即可理解）、**富含事实**（包含具体统计数据、日期或命名实体）、**在前1-2句直接回答问题**。

这与传统SEO文案写作根本不同，传统SEO优化关键词密度和用户参与度指标。GEO可引用性优化**可提取性**——AI系统从内容中提取段落并将其作为直接答案呈现的难易程度。

## 可引用性评分规则（0-100）

### 类别1：答案块质量（总分30%）

衡量内容是否包含AI系统可直接提取的清晰、可引用答案段落。

**评分标准：**

| 评分 | 标准 |
|---|---|
| **90-100** | 每个主要部分以1-2句直接答案开头。使用"X是..."或"X指..."模式。每个部分的前40-60词可作为完整答案独立存在。 |
| **70-89** | 大多数部分有清晰的答案开头。存在一些定义模式。答案可识别但可能需要轻微上下文。 |
| **50-69** | 部分部分有类似答案的开头，但许多在段落中间或末尾埋入答案。很少有明确的定义模式。 |
| **30-49** | 答案通常埋入长段落。没有一致的定义模式。内容是叙述驱动而非答案驱动。 |
| **0-29** | 没有可识别的答案块。内容完全是叙述、对话或碎片化的。AI几乎无法提取任何可引用段落。 |

**寻找的内容：**
- **定义模式**："X是[定义]。" / "X指[解释]。" / "X意思是[含义]。"
- **答案优先结构**：答案出现在第一句，后面跟支持细节。
- **量化答案**："X的平均成本是$Y"而非"许多因素影响X的成本。"
- **对比答案**："X与Y在三个方面不同：[列表]"而非"X和Y经常被混淆。"

### 类别2：段落自包含（总分25%）

衡量单个段落是否可以提取并在不需要周围内容的情况下被理解。

**评分标准：**

| 评分 | 标准 |
|---|---|
| **90-100** | 80%+的内容块完全自包含。每个段落明确命名其主题。不依赖指向前文内容的代词。段落内包含具体事实。 |
| **70-89** | 60-79%的内容块自包含。大多数段落命名其主题。偶尔需要上下文的代词引用。 |
| **50-69** | 40-59%的内容块自包含。明确主题和代词的混合使用。部分段落需要阅读前文部分。 |
| **30-49** | 20-39%的内容块自包含。严重依赖代词和上下文引用。大多数段落需要周围文本。 |
| **0-29** | 自包含低于20%。内容阅读为连续叙事，提取任何段落都会丢失含义。 |

**每个段落的自包含检查清单：**
1. 段落是否明确命名主题（不是"它"、"这"、"他们"）？
2. 仅阅读此段落时能理解要点吗？
3. 段落是否包含至少一个具体事实、统计数据或命名实体？
4. 段落长度在50-200词之间（最佳提取长度）？
5. 段落是否避免以连词开头（"但是"、"然而"、"而且"）暗示前文上下文？

### 类别3：结构可读性（总分20%）

衡量帮助AI系统解析和分段内容的结构格式。

**评分标准：**

| 评分 | 标准 |
|---|---|
| **90-100** | 清晰的H1>H2>H3层次结构。信息内容使用基于问题的标题。短段落（2-4句）。对比使用表格。流程使用有序列表。特征/选项使用无序列表。 |
| **70-89** | 良好的标题层次结构，略微跳过。一些基于问题的标题。大多数短段落。一些表格和列表的使用。 |
| **50-69** | 存在但不一致的标题层次结构。很少有基于问题的标题。长短段落混合。有限的表格/列表。 |
| **30-49** | 最小的标题结构。没有基于问题的标题。长段落占主导。很少使用表格/列表。 |
| **0-29** | 没有标题结构或严重破坏的层次结构。大段文本段落。没有表格或列表。 |

**AI可引用性的结构最佳实践：**
- **标题层次**：H1（页面标题）> H2（主要部分）> H3（子部分）。永远不要跳级。
- **基于问题的标题**："什么是[主题]？"和"[主题]如何运作？"可直接匹配AI查询。
- **段落长度**：每段2-4句。AI系统更可靠地解析短段落。
- **表格**：3+项的任何对比使用。AI系统以高精度提取表格数据。
- **列表**：顺序流程使用有序列表，非顺序项使用无序列表。
- **加粗关键术语**：加粗重要术语的首次使用。这有助于AI实体识别。

### 类别4：统计密度（总分15%）

衡量是否存在AI系统在选择引用来源时优先考虑的具体、可验证数据点。

**评分标准：**

| 评分 | 标准 |
|---|---|
| **90-100** | 每500词5+个具体统计数据。所有声明都有命名来源或日期。使用精确数字（不是"许多"或"几个"）。包括百分比、美元金额、时间框架和命名研究。 |
| **70-89** | 每500词3-4个统计数据。大多数声明有来源。大部分是具体数字，偶尔有模糊限定词。 |
| **50-69** | 每500词1-2个统计数据。部分声明有来源。具体和模糊数字混合。 |
| **30-49** | 每500词少于1个统计数据。很少有来源声明。主要是模糊限定词。 |
| **0-29** | 没有统计数据。没有有来源的声明。所有限定词都是模糊的（"许多"、"大多数"、"很多"）。 |

**计入统计的内容：**
- 具体百分比："73%的营销人员报告..."
- 美元金额："平均成本是每月$4,500"
- 时间框架："实施平均需要6-8周"
- 命名研究："根据2025年HubSpot营销状况报告..."
- 具体数量："平台与340+工具集成"
- 对比数据："比行业平均水平快40%"

**不计入的内容：**
- "许多公司使用..."（模糊）
- "一个重要百分比..."（模糊）
- "研究表明..."（没有命名来源）
- "专家同意..."（没有命名专家）

### 类别5：独特性与原始数据（总分10%）

衡量内容是否提供AI系统无法在其他地方找到的信息，使其成为必要的引用来源。

**评分标准：**

| 评分 | 标准 |
|---|---|
| **90-100** | 包含一手研究、专有数据、原创调查或独特数据集。呈现任何其他页面都找不到的分析或见解。清晰的方法论描述。 |
| **70-89** | 包含一些原创见解或对现有数据的独特分析。具有原创示例的独特视角。 |
| **50-69** | 主要综合现有信息，但添加一些独特评论或示例。 |
| **30-49** | 主要是衍生内容，重述常识，贡献极少。 |
| **0-29** | 完全衍生。所有信息可在更高权威来源获得（通常是逐字逐句）。 |

**独特内容的信号：**
- "我们对[X]数据的分析发现..."
- "我们调查了[N]位[专业人士]发现..."
- "基于我们与[N]个客户的经验..."
- 自定义图表、图形或数据可视化
- 具有特定命名结果的案例研究
- 原创框架、方法论或分类法

## 分析程序

### 步骤1：获取并解析页面内容

1. 使用WebFetch检索目标URL。
2. 提取主内容区域（排除导航、页脚、侧边栏、广告）。
3. 保留标题结构（H1-H6标签）。
4. 保留段落边界、列表和表格。
5. 计算主内容总字数。

### 步骤2：将内容分段为块

1. 在每个标题（H2或H3）处分割内容以创建内容块。
2. 对于每个块，记录：
   - 标题文本
   - 该标题下的完整文本内容
   - 块的字数
   - 段落数
   - 列表和表格数
   - 统计数据/数据点数
   - 块是否包含定义模式
   - 前60词是否形成独立答案

### 步骤3：评分每个块

对于每个内容块，计算：
- 答案块质量子评分（0-100）
- 自包含子评分（0-100）
- 结构可读性子评分（0-100）
- 统计密度子评分（0-100）
- 独特性子评分（0-100）

**块可引用性评分** = (答案 * 0.30) + (自包含 * 0.25) + (结构 * 0.20) + (统计 * 0.15) + (独特 * 0.10)

### 步骤4：计算页面级评分

1. 计算所有块评分的平均值作为页面级可引用性评分。
2. 识别前3个最高评分块（突出为优势）。
3. 识别后3个最低评分块（标记为需要重写）。
4. 计算评分高于70的块百分比（"可引用覆盖率"指标）。

### 步骤5：生成重写建议

对于每个评分低于60的块，生成具体重写建议：
1. 识别主要弱点（埋入答案、缺乏事实、结构差等）。
2. 使用定义或答案优先模式提出重写开头句。
3. 建议可添加的具体统计数据或事实。
4. 建议结构改进（添加列表、添加表格、拆分段落）。

## AI引用的最佳段落特征（来自GEO研究）

- **AI引用最佳长度：** 134-167词（Bortolato 2025年AI Overview段落分析）
- **定义模式增加引用率：** 2.1倍（佐治亚理工2024年）
- **向段落添加统计数据使引用增加：** 40%（普林斯顿GEO研究2024年）
- **添加权威引用使某些类别引用增加：** 115%（IIT德里2024年）
- **流畅性优化使所有查询类型平均可见度增加：** 30%
- **带有来源引用的内容被Perplexity和ChatGPT引用：** 多20-25%

## AI系统引用偏好

| AI系统 | 引用偏好 |
|---|---|
| **ChatGPT（搜索）** | 偏好明确引用、命名来源和近期日期的段落。倾向于每个响应引用2-4个来源。 |
| **Perplexity** | 严重偏向富含事实的段落。在每个响应中引用4-8个来源。高度重视新鲜度。 |
| **Claude** | 偏好结构良好、全面的段落。重视细微差别和准确性而非简洁。 |
| **Gemini（AI Overviews）** | 偏好简洁答案块（40-60词）。重视已排在自然结果前10的内容。 |
| **Copilot（Bing）** | 与Gemini类似。偏好来自高权威域的清晰事实声明段落。 |

## 扣子部署建议

### 推荐插件
- **网页内容解析**：用于提取和分析页面内容
- **数据计算**：用于评分计算

### 适用场景
- 内容创作者优化文章以提高AI引用率
- SEO团队评估现有内容的GEO准备度
- 内容编辑进行发布前内容审查
- 营销团队识别需要重写的低绩效内容

### 典型工作流程
```
输入URL → 内容提取 → 分块 → 5维度评分 → 识别改进点 → 输出建议
```

### 核心输出
- 总体可引用性评分（0-100）
- 5个维度的详细评分
- 最强/最弱内容块识别
- 具体重写建议
- 快速见效优化建议
