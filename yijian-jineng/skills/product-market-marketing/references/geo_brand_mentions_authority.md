# 品牌提及与权威度扫描

## 基本信息
- **英文原名**: geo-brand-mentions
- **所属项目**: geo-seo-claude
- **核心能力**: 分析品牌在AI模型依赖进行实体识别和引用决策的平台上存在情况。生成品牌权威评分（0-100）及平台特定建议。

## 核心洞察

品牌提及与AI可见性的相关性约为传统反链的3倍。Ahrefs于2025年12月发布的研究，分析了跨AI搜索平台的75,000个品牌，发现**无链接品牌提及**——没有超链接的品牌名称引用——比域名评级或反链数量更能预测AI系统是否引用和推荐品牌。

关键发现：**提及出现的平台非常重要。** 不是所有提及都是平等的。YouTube或Reddit上的提及比低权威博客上的提及对AI引用的权重高得多，因为AI训练数据和检索系统不成比例地索引高参与度平台。

这颠覆了传统SEO的核心假设。在传统SEO中，来自高DR网站的反链是黄金标准。在GEO中，Reddit上或YouTube视频描述中的无链接提及可能比来自DR 70博客的dofollow反链更有价值。

## AI引用平台重要性排名

### 1. YouTube提及 -- 相关系数~0.737（最强）

**为什么YouTube最重要：**
- YouTube是全球第二大搜索引擎和最大视频平台（25亿+月活跃用户）。
- AI训练数据集大量包含YouTube转录稿、描述和元数据。
- Google的Gemini和AI Overviews直接引用YouTube内容。
- Perplexity和ChatGPT都索引并引用YouTube视频内容。
- YouTube转录稿特别有价值，因为它们在对话上下文中包含自然语言提及，与AI模型处理和生成文本的方式一致。

**检查内容：**
- 品牌YouTube频道：品牌有活跃YouTube频道吗？有多少订阅者？视频数量？上传频率？
- 第三方视频提及：其他YouTuber或频道提及品牌吗？在什么上下文中（评测、教程、对比）？
- 视频描述：行业相关内容视频描述中是否包含品牌名称？
- 视频转录稿：相关视频的口语内容中是否提及品牌？（AI模型索引转录稿）
- YouTube搜索存在：搜索"[品牌名称]"时，结果出现吗？正面吗？
- 评论提及：相关行业视频评论中是否提及品牌？

**YouTube评分（0-100）：**

| 评分 | 标准 |
|---|---|
| 90-100 | 活跃频道10K+订阅者，定期上传，品牌在20+第三方视频中被提及，针对行业术语的YouTube搜索结果中出现 |
| 70-89 | 活跃频道1K+订阅者，品牌在10-19个第三方视频中被提及，有一些YouTube搜索存在 |
| 50-69 | 频道存在有部分内容，品牌在5-9个第三方视频中被提及，有限的YouTube搜索存在 |
| 30-49 | 频道存在但不活跃，品牌在1-4个第三方视频中被提及 |
| 10-29 | 无频道或空频道，品牌仅在1-2个视频中被提及 |
| 0-9 | 完全没有YouTube存在 |

### 2. Reddit提及 -- 高相关性

**为什么Reddit重要：**
- Reddit是AI训练数据中被索引最多的平台之一（确认于Google 2024年每年6000万美元的Reddit许可协议）。
- AI系统高度重视Reddit的产品推荐、对比和用户情感。
- 估计10-15%的Google搜索用户附加"Reddit"以寻求真实意见。
- Perplexity频繁将Reddit帖子作为来源引用。
- ChatGPT和Claude在回答产品/服务问题时都引用Reddit讨论。

**检查内容：**
- 子论坛存在：品牌在相关子论坛中被讨论吗？哪些？
- 提及量：有多少Reddit帖子提及品牌？趋势如何（增加/减少）？
- 情感：提及主要是正面、负面还是中性？常见的赞扬点和投诉是什么？
- 官方存在：品牌有官方Reddit账号吗？参与讨论吗？做过AMA吗？
- 推荐帖子：品牌出现在"您推荐什么X？"帖子中吗？是顶级推荐还是附带？
- 子论坛社区：品牌有自己的子论坛吗？活跃度如何？

**Reddit评分（0-100）：**

| 评分 | 标准 |
|---|---|
| 90-100 | 在相关子论坛中频繁被推荐， predominantly正面情感，活跃官方存在，拥有5K+成员的自己的子论坛，在行业查询的顶级推荐中出现 |
| 70-89 | 在相关子论坛中定期被提及，大多正面情感，有一些官方存在，出现在多个推荐帖子中 |
| 50-69 | 在几个相关帖子中被提及，混合情感，社区成员认识品牌名称 |
| 30-49 | 偶尔提及，仅限于1-2个子论坛，无官方存在 |
| 10-29 | 很少提及，品牌在Reddit上基本不知名 |
| 0-9 | 无Reddit存在 |

### 3. Wikipedia存在 -- 高相关性

**为什么Wikipedia重要：**
- Wikipedia是AI训练数据中最高权威来源之一。所有主要AI模型都使用Wikipedia转储进行训练。
- AI系统使用Wikipedia作为实体识别的主要来源——确定品牌是否是"真实"实体。
- Wikidata（Wikipedia的结构化数据兄弟）提供AI模型用于知识图谱构建的机器可读事实。
- 拥有Wikipedia页面是显著性的强烈信号，与AI系统将品牌视为权威实体相关。

**检查内容：**
- Wikipedia页面：品牌或公司有自己的Wikipedia文章吗？标记删除或质量问题了吗？
- 创始人页面：创始人/CEO有Wikipedia页面吗？（强烈权威信号）
- Wikipedia引用：品牌网站被引用为任何Wikipedia文章的参考吗？
- Wikidata条目：品牌有Wikidata项目（Q号）吗？完整性如何？
- Wikipedia提及：品牌在其他Wikipedia文章中被提及吗（行业文章、竞争对手页面、类别页面）？
- 文章质量：如果Wikipedia页面存在，是短条目、起始级还是更高质量？

**Wikipedia评分（0-100）：**

| 评分 | 标准 |
|---|---|
| 90-100 | 详细Wikipedia文章（B级或更高），包含完整属性的Wikidata条目，品牌在多篇文章中被引用为参考，创始人有Wikipedia页面 |
| 70-89 | Wikipedia文章存在（起始级或更高），Wikidata条目存在，品牌在2+其他Wikipedia文章中被提及 |
| 50-69 | Wikipedia文章存在（短条目或起始级），基本Wikidata条目，在其他文章中有限提及 |
| 30-49 | 无Wikipedia文章但品牌在其他文章中被提及或被引用为参考；可能有Wikidata条目 |
| 10-29 | 品牌在1-2个Wikipedia文章中仅作为路过引用提及 |
| 0-9 | 完全没有Wikipedia或Wikidata存在 |

### 4. LinkedIn存在 -- 中等相关性

**为什么LinkedIn重要：**
- LinkedIn内容日益被AI系统索引，用于专业和B2B背景。
- 公司LinkedIn页面和员工思想领导力帖子建立品牌实体信号。
- AI模型引用LinkedIn获取公司信息、团队资质和专业权威。
- LinkedIn文章和帖子被搜索引擎和AI爬虫索引。

**检查内容：**
- 公司页面：品牌公司LinkedIn页面存在吗？完整吗？
- 追随者数量：页面有多少追随者？
- 帖子频率：发布频率如何？
- 员工数量：列出多少员工？
- 参与度：帖子的参与度水平如何？
- 思想领导力：领导或员工是否发布思想领导力内容？
- 官方账号：品牌是否有官方LinkedIn账号？

### 5. 其他平台

#### 新闻/出版
- **相关性：** 中高
- **检查：** 品牌在主要新闻来源中被提及吗？科技/商业出版物？行业特定出版物？
- **信号强度：** 中高，但集中于权威来源

#### Quora
- **相关性：** 中等
- **检查：** 品牌在Quora答案中被提及吗？品牌官方是否回答问题？
- **信号强度：** 中等，且增长

#### Stack Overflow / GitHub（技术品牌）
- **相关性：** 高（技术品牌）
- **检查：** 品牌在Stack Overflow问题/答案中被提及吗？GitHub上有官方账号吗？
- **信号强度：** 高（技术品牌），低（非技术品牌）

#### Hacker News
- **相关性：** 中等
- **检查：** 品牌在Hacker News讨论中被提及吗？
- **信号强度：** 中等，但高影响力的提及

#### 播客
- **相关性：** 增长中
- **检查：** 品牌或其领导出现在播客上吗？提及品牌的播客转录稿被搜索引擎索引吗？
- **信号强度：** 中等且增长

## 品牌权威评分公式

### 评分权重

| 平台 | 权重 | 理由 |
|---|---|---|
| YouTube存在 | 25% | 与AI引用最强相关性（0.737） |
| Reddit存在 | 25% | 第二强相关性；对产品推荐至关重要 |
| Wikipedia / Wikidata | 20% | 实体识别基础；AI训练数据基石 |
| LinkedIn权威 | 15% | 专业权威信号；B2B相关性 |
| 其他平台 | 15% | Quora、GitHub、新闻、论坛、播客的补充信号 |

**公式：**
```
Brand_Authority_Score = (YouTube * 0.25) + (Reddit * 0.25) + (Wikipedia * 0.20) + (LinkedIn * 0.15) + (Other * 0.15)
```

### 评分解读

| 评分范围 | 等级 | 解读 |
|---|---|---|
| 85-100 | 主导 | 品牌是跨AI平台的知名实体。极有可能被AI系统引用和推荐。 |
| 70-84 | 强劲 | 品牌有坚实的跨平台存在。AI系统可能为相关查询识别并引用它。 |
| 50-69 | 中等 | 品牌在部分平台有存在但存在差距。AI引用不一致。 |
| 30-49 | 较弱 | 品牌平台存在有限。AI系统可能不将其识别为独立实体。 |
| 0-29 | 极小 | 品牌几乎没有平台存在。AI系统不太可能引用或推荐它。 |

## 参考数据

### 相关强度（Ahrefs 2025年12月，75K品牌）

| 信号 | 与AI引用的相关性 | 传统SEO价值 |
|---|---|---|
| YouTube提及 | ~0.737 | 低（非排名因素） |
| Reddit提及 | 高（确切系数未发布） | 低 |
| Wikipedia存在 | 高 | 中等（信任信号） |
| LinkedIn存在 | 中等 | 低 |
| 域名评级 | ~0.266 | 非常高 |
| 反链数量 | ~0.266 | 非常高 |
| 自然流量 | 中等 | 非常高 |

**关键洞察：** 对AI可见性最重要的信号（YouTube、Reddit）在传统SEO中几乎无关，而对传统SEO最重要的信号（反链、DR）对AI可见性是弱预测因子。这需要从根本上不同的优化策略。

- 综合品牌权威评分（0-100）

- 竞争对比（如果提供竞争对手）
