## 工作流总览

```
输入：平台+账号ID/链接+产品信息
  ↓
阶段1：账号诊断与画像 → 输出：账号画像卡
  ↓
阶段2：内容策略决策 → 输出：策略配置（5维决策结果）
  ↓
阶段3：脚本创作引擎 → 输出：完整脚本+分镜表+互动话术
  ↓
阶段4：视听素材规划 → 输出：素材清单+视听规格
  ↓
阶段5：成片输出 → 输出：短视频/图文/文章成品方案
```

触发条件："帮我做爆款视频""分析我的账号做内容""帮我生成小红书图文""帮我写种草脚本""生产爆款内容"

## 阶段1：账号诊断与画像

### 输入
- 平台名称（抖音/小红书/B站/快手/视频号/头条）
- 账号ID或主页链接
- 补充信息（可选）：产品信息、商业目标、预算范围

### 分析维度

#### 1. 粉丝画像分析
| 维度 | 分析项 | 判定方法 |
|------|--------|----------|
| 年龄段 | 18-24/25-30/31-40/40+ | 从内容调性和评论互动推断 |
| 性别比 | 男:女比例 | 从内容类型和互动风格推断 |
| 地域分布 | 一线/新一线/二三线/下沉 | 从方言、场景、消费力推断 |
| 消费力 | 低/中/高 | 从带货产品价格带推断 |

#### 2. 内容标签分析
- 主标签：账号核心定位标签（1-2个，如"美妆护肤""家居好物"）
- 辅标签：关联内容标签（2-3个，如"成分党""平价替代"）
- 标签关联度：主辅标签之间的一致性评估

#### 3. 互动数据分析
| 指标 | 计算方式 | 健康基准 |
|------|----------|----------|
| 均播 | 总播放/视频数 | 粉丝数×3-10倍 |
| 赞粉比 | 均赞/粉丝数 | >3% |
| 评赞比 | 均评论/均赞 | >5%（高互动） |
| 收藏率 | 均收藏/均播 | >2%（干货型可>5%） |
| 转粉率 | 新增粉丝/播放 | >0.5% |

#### 4. 内容风格判定
| 风格 | 特征 | 适合品类 |
|------|------|----------|
| 专业型 | 条理清晰、数据支撑、逻辑强 | 数码/保健/金融 |
| 亲和型 | 邻家感、真实分享、聊天式 | 美妆/母婴/家居 |
| 潮流型 | 视觉冲击、快节奏、前沿感 | 服饰/潮玩/数码 |
| 故事型 | 情节驱动、情感共鸣、沉浸感 | 食品/礼品/旅游 |

#### 5. 竞品对标
- 同赛道Top5账号特征提取
- 差异化机会点识别（内容空白区/风格空白区/人群空白区）

见 [账号画像卡模板](#账号画像卡模板)

## 阶段2：内容策略决策矩阵

### 决策1：商业目标→种草类型

```
商业目标？
├── 即时转化（7天内见效）
│   └── 硬性种草
│       ├── 抖音：痛点解决型/对比测评型/权威背书型
│       └── 小红书：好物分享型/专业测评型/避坑指南型
├── 品牌建设（1-12个月累积）
│   └── 软性种草
│       ├── 短视频：生活vlog型/干货分享型/情绪故事型
│       └── 小红书：意外发现型/氛围感大片型/使用日记型
└── 两者兼顾
    └── 先软后硬组合策略
        ├── 蓄水期（1-4周）：软性种草建立信任
        ├── 加速期（4-8周）：软性扩大覆盖
        └── 收割期（8-12周）：硬性驱动转化
```

### 决策2：内容形式→输出平台

| 内容形式 | 首选平台 | 时长/篇幅 | 画幅 |
|----------|----------|-----------|------|
| 短视频 | 抖音/快手/视频号 | 15-60秒 | 9:16竖屏 |
| 中视频 | B站/西瓜 | 1-5分钟 | 16:9横屏或9:16 |
| 图文笔记 | 小红书 | 3-9张图+500字 | 3:4或1:1 |
| 长文章 | 头条/百家号/订阅号 | 1500-3000字 | N/A |
| 多平台适配 | 全平台 | 按平台调整 | 按平台调整 |

### 决策3：内容类型→创作方向

| 内容类型 | 适用场景 | 核心结构 | 适合品类 |
|----------|----------|----------|----------|
| 知识科普型 | 新品类教育/专业产品 | 痛点→原理→方案→产品 | 保健/数码/护肤 |
| 测评对比型 | 有竞品/需决策参考 | 背景→实测→对比→结论 | 美妆/数码/家电 |
| 使用教程型 | 复杂产品/功能多 | 痛点→分步→效果→要点 | 工具/软件/电器 |
| 生活vlog型 | 生活类/场景化 | 场景→融入→体验→收束 | 家居/食品/日用 |
| 情绪故事型 | 情感驱动/礼品类 | 情绪→困境→转折→解决 | 礼品/美食/旅游 |
| 好物分享型 | 通用百搭/日常种草 | 发现→体验→细节→推荐 | 全品类 |

### 决策4：发布方式→渠道选择

| 发布方式 | 适用场景 | 优势 | 劣势 |
|----------|----------|------|------|
| 自营号发布 | 品牌号/矩阵号 | 可控性强/成本低 | 起量慢/信任度低 |
| 达人合作 | KOC种草/KOL引爆 | 信任度高/起量快 | 成本高/可控性低 |
| 混合策略 | 自营+达人组合 | 兼顾可控与起量 | 协调复杂 |

### 决策5：转化路径→行动设计

| 转化路径 | 适用产品 | 行动指令示例 | 效果周期 |
|----------|----------|-------------|----------|
| 挂车带货 | 标品/低决策成本 | "左下角直接拍""购物车已上架" | 即时 |
| 直播间引导 | 需讲解/高互动 | "今晚8点直播间""直播间有专属价" | 1-3天 |
| 搜索引导 | 高客单价/需比较 | "搜XX品牌""官方旗舰店" | 3-7天 |
| 私域沉淀 | 高复购/需长期运营 | "主页加群""进群领福利" | 长期 |

### 决策输出：策略配置表

```json
{
  "商业目标": "即时转化/品牌建设/组合",
  "种草类型": "硬性/软性/组合",
  "内容形式": "短视频/图文/文章/多平台",
  "目标平台": ["抖音", "小红书"],
  "内容类型": "知识科普/测评对比/使用教程/生活vlog/情绪故事/好物分享",
  "发布方式": "自营号/达人合作/混合",
  "转化路径": "挂车带货/直播间引导/搜索引导/私域沉淀"
}
```

## 阶段3：脚本创作引擎

### Step 1：钩子选择

从40+钩子库中匹配最适合的3秒开场，匹配逻辑：

| 账号风格 | 推荐钩子类型 | 示例 |
|----------|-------------|------|
| 专业型 | 数据冲击/权威引用 | "90%的人不知道..." |
| 亲和型 | 共鸣痛点/生活场景 | "你是不是也..." |
| 潮流型 | 反常识/视觉冲击 | "千万别再用XX了" |
| 故事型 | 悬念设置/情绪触发 | "那天我差点..." |

钩子详细库见 references/hook-library.md

### Step 2：框架匹配

根据阶段2的策略配置，自动匹配对应框架：

**硬性种草框架**（即时转化）：
- 抖音6种：痛点解决型/场景代入型/对比测评型/教程干货型/情绪共鸣型/权威背书型
- 小红书6种：好物分享型/使用教程型/避坑指南型/成分党型/生活记录型/专业测评型
- 详见 references/seeding-copywriting-framework.md

**软性种草框架**（品牌建设）：
- 短视频5种：生活vlog露出/干货+工具/情绪故事/使用体验/对比评测
- 小红书5种：意外发现/踩坑避坑/成分技术党/氛围感大片/使用日记
- 文章6种：知识科普/行业分析/个人经历/问题解决/观点输出/SEO优化
- B站6种：测评/开箱/教程/行业解析/UP主日常/横向对比
- 详见 references/soft-seeding-framework.md

**5步转化漏斗框架**（通用带货口播）：
- 症状聚焦→原因深挖→错误处理→高难度方案→简单方案
- 详见 references/short-video-script-framework.md

### Step 3：脚本撰写

按选定框架逐段生成，每段包含：

| 段落 | 时长占比 | 内容 | 画面描述 |
|------|----------|------|----------|
| 钩子(0-3s) | 5% | 抓注意力的开场 | 对应视觉冲击画面 |
| 痛点/场景(3-10s) | 15% | 引发共鸣的问题 | 痛点场景展示 |
| 产品/方案(10-30s) | 40% | 核心价值传递 | 产品展示/使用画面 |
| 证明/对比(30-45s) | 25% | 效果验证 | 前后对比/数据展示 |
| 行动号召(45-60s) | 15% | 转化引导 | 行动指示画面 |

### Step 4：互动设计

| 互动类型 | 设计要点 | 示例 |
|----------|----------|------|
| 评论区引导 | 置顶评论引发讨论 | "你们觉得XX和XX哪个好用？" |
| 点赞引导 | 在价值输出点后自然引导 | "觉得有用的点个赞" |
| 收藏引导 | 干货内容必加 | "建议收藏，下次买不踩坑" |
| 关注引导 | 在人设输出后引导 | "关注我，持续分享XX干货" |
| 话题标签 | 3-5个标签 | #好物推荐 #平价替代 #测评 |

见 [脚本输出模板](#脚本输出模板)

## 阶段4：视听素材规划

### 视频素材规划

#### 素材类型选择

| 素材类型 | 适用场景 | 优势 | 制作难度 |
|----------|----------|------|----------|
| 实拍 | 产品展示/使用场景 | 真实感强/信任度高 | 高 |
| 素材库混剪 | 科普/知识分享 | 成本低/效率高 | 低 |
| 动画/图形 | 数据展示/原理讲解 | 信息清晰/专业感强 | 中 |
| AI生成 | 概念展示/氛围营造 | 创意空间大/成本低 | 低 |
| 图文轮播 | 小红书图文笔记 | 制作简单/信息密度高 | 低 |

#### 时长规划

| 时长 | 适合平台 | 内容节奏 | 框架选择 |
|------|----------|----------|----------|
| 15秒 | 抖音/快手 | 极快：3s钩子+7s卖点+5s行动 | 痛点解决/好物分享 |
| 30秒 | 抖音/快手/视频号 | 快：3s钩子+12s产品+10s证明+5s行动 | 场景代入/对比测评 |
| 45秒 | 抖音/视频号 | 中快：3s钩子+15s产品+17s证明+10s行动 | 教程干货/权威背书 |
| 60秒 | 抖音/B站 | 中：3s钩子+20s产品+22s证明+15s行动 | 情绪共鸣/完整故事 |
| 3-5分钟 | B站/西瓜 | 中慢：完整叙事+深度内容 | 测评/教程/解析 |
| 10-25分钟 | B站 | 慢：深度内容+详细评测 | 横向对比/行业解析 |

#### 画幅选择
- 9:16竖屏：抖音/快手/视频号/小红书视频
- 16:9横屏：B站/西瓜/头条视频
- 3:4或1:1：小红书图文
- 4:3或16:9：文章配图

### 配音规划

#### 音色选择矩阵

| 产品调性 | 推荐音色 | 语速 | 情绪 | 适合品类 |
|----------|----------|------|------|----------|
| 专业权威 | 磁性/沉稳 | 中 | 冷静/自信 | 数码/金融/保健 |
| 温暖亲和 | 柔和/温暖 | 中慢 | 温暖/真诚 | 母婴/家居/日用 |
| 活力潮流 | 明快/活力 | 快 | 激情/兴奋 | 美妆/服饰/潮玩 |
| 知性优雅 | 清亮/知性 | 中 | 从容/优雅 | 护肤/美食/旅游 |
| 搞笑幽默 | 夸张/搞怪 | 快慢交替 | 幽默/反转 | 零食/创意品/趣味 |
| 少女清新 | 甜美/少女 | 中 | 天然/可爱 | 美妆/文具/甜品 |

#### 配音规格
- 语速：快(5字/秒)/中(3-4字/秒)/慢(2字/秒)
- 音量：人声-12dB/BGM-20dB/音效-16dB
- 格式：MP3/AAC，44.1kHz，立体声

### BGM规划

| 内容节奏 | BGM风格 | 推荐类型 | 音量比 |
|----------|---------|----------|--------|
| 快节奏剪辑 | 电子/流行/说唱 | 节拍感强，120+ BPM | 人声:BGM = 3:1 |
| 慢节奏叙事 | 轻音乐/钢琴/弦乐 | 温暖舒缓，60-80 BPM | 人声:BGM = 4:1 |
| 悬念反转 | 电影感/紧张 | 渐进式，有起伏 | 人声:BGM = 2:1 |
| 日常分享 | 民谣/Lo-fi/轻快 | 轻松不抢人声 | 人声:BGM = 5:1 |

版权注意：使用免版权音乐库或购买商用授权

### 字幕规划

| 字幕类型 | 样式 | 适用场景 |
|----------|------|----------|
| 基础字幕 | 白底黑字/黄底黑字，居中下方 | 通用 |
| 花字特效 | 品牌色背景+大字，关键信息高亮 | 卖点/价格/行动号召 |
| 手写体 | 手写风格，随配音逐字出现 | 温馨/个人化内容 |
| 弹跳字幕 | 文字弹跳动画出现 | 活力/潮流内容 |
| 关键词高亮 | 重要词变色/放大/描边 | 核心卖点/数据 |

字幕规范：
- 字号：标题36-48pt/正文24-32pt
- 位置：居中下方（避开平台UI区域）
- 关键词高亮：每段最多高亮2-3个词
- 时长：与配音严格同步，每字显示时间>=0.3秒

### 转场规划

| 转场类型 | 适用场景 | 时长 | 注意事项 |
|----------|----------|------|----------|
| 硬切 | 快节奏/信息密度高 | 0s | 最常用，节奏感强 |
| 叠化 | 慢节奏/情感过渡 | 0.3-0.5s | 过渡柔和，不宜多用 |
| 推拉 | 场景切换/空间转换 | 0.3-0.5s | 有方向感 |
| 缩放 | 强调细节/聚焦重点 | 0.2-0.3s | 配合音效更有力 |
| 旋转 | 活力/潮流风格 | 0.3s | 谨慎使用，易眩晕 |
| 创意转场 | 品牌特色/个性化 | 0.3-0.5s | 需设计，成本高 |

转场节奏：配合BGM节拍点切换，每2-4秒一个切换点

### 视觉资产规划

| 资产类型 | 数量 | 规格 | 用途 |
|----------|------|------|------|
| 封面图 | 1张 | 1080×1920(竖)/1080×1440(3:4) | 视频封面/图文封面 |
| 分镜图片 | 4-8张 | 1080×1920 | 视频画面 |
| 转场图片 | 2-3张 | 1080×1920 | 场景过渡 |
| 内页图 | 3-9张 | 1080×1440 | 小红书图文内页 |
| 信息图 | 1-2张 | 1920×1080 | 数据展示/对比 |

## 阶段5：成片输出

### 短视频输出流程

```
分镜脚本 → 生成分镜图片 → 配音录制 → 字幕叠加 → 转场添加 → BGM/音效 → 合成指导
```

智能体执行步骤：
1. 按脚本分镜逐段描述图片生成需求，生成对应画面
2. 确定配音方案（音色/语速/情绪），生成配音文本标注
3. 确定字幕样式，标注关键词高亮位置
4. 确定转场方案，标注切换点和类型
5. 输出合成指导文档（含时间轴、画面、音频、字幕、转场的完整编排）

### 小红书图文输出流程

```
策略配置 → 封面设计 → 内页设计 → 笔记文案 → 话题标签
```

智能体执行步骤：
1. 生成封面图：品牌色+大标题+产品/场景主视觉
2. 生成内页图：产品展示/使用场景/细节特写/效果对比/成分解析/使用步骤
3. 撰写笔记文案：标题(含关键词)+正文(含emoji分段)+标签(3-5个)
4. 输出完整小红书图文方案

### 文章输出流程

```
策略配置 → 标题SEO优化 → 正文结构化撰写 → 配图描述 → 关键词布局
```

智能体执行步骤：
1. 生成3个备选标题（含核心关键词，20-30字）
2. 按框架结构化撰写正文（H2/H3含长尾关键词）
3. 为每个段落设计配图描述
4. 关键词密度2%-5%，自然分布

## 多平台一源多发适配规则

### 适配优先级

1. 先确定核心素材（脚本/文案/图片）
2. 选定首发平台，生成首发版本
3. 按适配规则逐平台调整

### 各平台适配检查清单

| 检查项 | 抖音 | 小红书 | 头条 | B站 |
|--------|------|--------|------|-----|
| 标题改写 | 钩子式3秒 | 关键词+人群 | 悬念+SEO | 价值预告 |
| 时长/篇幅 | 15-60s | 3-9图+500字 | 1500-3000字 | 5-25min |
| 开头改写 | 强情绪 | 场景发现 | 悬念引入 | 价值预告 |
| 结尾改写 | 行动号召 | 轻引导 | 总结建议 | 三连引导 |
| 图片调整 | 冲击力 | 精致拼图 | 信息图 | 封面吸引力 |
| 标签调整 | 3-5个 | 5-10个 | 嵌入正文 | 标签+分区 |
| 互动设计 | 评论区 | 收藏引导 | 评赞互动 | 弹幕+三连 |

### 一源多发效率公式

```
核心素材(1份) + 平台适配(每平台20%调整) = N平台内容矩阵
```

建议顺序：小红书图文(素材最全)→抖音短视频(视频化)→头条文章(深度化)→B站长视频(专业化)
