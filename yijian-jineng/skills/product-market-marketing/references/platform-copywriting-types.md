## 短视频平台文案类型

### 1.1 抖音文案类型

#### 类型1：带货文案
**文案特点**：
- 前三秒抓住用户注意力
- 痛点→解决方案→产品→优惠→引导转化
- 节奏紧凑，不拖沓
- 强调紧迫感，促进转化

**文案结构**：
```
[痛点] 最近皮肤总是暗沉长斑，怎么用护肤品都没用？
[共鸣] 有没有姐妹和我一样，真的很焦虑啊！
[解决方案] 直到我遇到了这款焕颜修护精华液！
[产品] 核心成分烟酰胺，修护肌肤屏障，改善敏感肌
[效果] 用了一个星期，皮肤真的变好了，不暗沉了，不长斑了
[优惠] 现在下单立减30元，还送小样，真的很划算！
[引导转化] 赶紧点击链接下单吧，手慢无！
```

**GEO优化要点**：
- 包含核心关键词：焕颜修护精华液、烟酰胺、肌肤屏障、敏感肌
- 使用口语化表达，贴近用户搜索习惯
- 强调产品功效，符合用户需求

#### 类型2：种草文案
**文案特点**：
- 真实体验分享
- 细节展示，突出品质
- 情感共鸣，增强信任
- 引导关注，建立粉丝关系

**文案结构**：
```
[开头] 最近在用的护肤品，真的太惊喜了！
[产品介绍] 这款焕颜修护精华液，是我用过的最好的修护精华
[使用体验] 质地清爽，吸收很快，不油腻
[效果展示] 用了一个月，皮肤真的变好了，细腻有光泽
[推荐理由] 适合敏感肌，温和不刺激，真的很好用
[引导关注] 想了解更多护肤干货，关注我吧！
```

**GEO优化要点**：
- 包含核心关键词：焕颜修护精华液、修护精华、敏感肌、清爽
- 使用真实体验语言，增强可信度
- 提供使用建议，帮助用户决策

#### 类型3：剧情文案
**文案特点**：
- 故事性强，吸引人
- 情感共鸣，引发关注
- 产品植入自然
- 引导转化，完成闭环

**文案结构**：
```
[故事背景] 每天加班到深夜，皮肤越来越差
[冲突] 同事聚会，被问是不是生病了
[转折] 朋友推荐这款焕颜修护精华液
[使用过程] 每天晚上坚持使用，期待效果
[结果] 一个月后，皮肤变好了，同事都问用了什么
[产品展示] 就是这款焕颜修护精华液，真的很好用
[引导转化] 想拥有好皮肤，赶紧点击链接吧！
```

**GEO优化要点**：
- 包含核心关键词：焕颜修护精华液、护肤、皮肤变好
- 使用故事化表达，增强代入感
- 强调产品效果，符合用户需求

**文案特点**：
- 专业测评，权威背书
- 对比展示，突出优势

**GEO优化要点**：
- 包含核心关键词：焕颜修护精华液、烟酰胺、敏感肌、性价比
- 使用专业术语，增强权威性

## 文案优化要点总结

### GEO优化通用要点
1. **关键词优化**：
   - 包含核心关键词、长尾关键词
   - 使用口语化表达，贴近用户搜索习惯
   - 关键词自然融入，不堆砌

2. **内容优化**：
   - 内容真实可信，不虚假宣传
   - 内容专业深度，增强权威性
   - 内容有价值，满足用户需求

3. **结构优化**：
   - 结构清晰，易于阅读
   - 重点突出，快速抓取
   - 逻辑清晰，易于理解

4. **互动优化**：
   - 引导互动，增强参与感
   - 引导分享，扩大传播
   - 引导转化，促进购买
