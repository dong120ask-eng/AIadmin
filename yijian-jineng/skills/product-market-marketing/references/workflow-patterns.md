## 模式1：知识科普类

### 适用场景
- 知识讲解
- 技能分享
- 行业揭秘

### 工作流结构

```
┌─────────────────────────────────────────────────────────────────┐
│                     知识科普类工作流                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐      │
│  │  选题   │───▶│  钩子   │───▶│  内容   │───▶│  结尾   │      │
│  │  策划   │    │  设计   │    │  展开   │    │  引导   │      │
│  └─────────┘    └─────────┘    └─────────┘    └─────────┘      │
│                                                                 │
│       │                                                   │    │
│       │           ┌─────────────────┐                    │    │
│       └──────────▶│   素材准备      │◀───────────────────┘    │
│                   └─────────────────┘                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 节点配置

#### 节点1：选题策划
```
输入：热点话题 / 用户痛点 / 专业领域
处理：关键词提取 → 角度选择 → 标题拟定
输出：选题清单 + 内容大纲
```

#### 节点2：钩子设计
```
输入：选题内容
处理：钩子匹配 → 钩子优化 → 开场设计
输出：3种钩子方案
```

#### 节点3：内容展开
```
输入：大纲 + 素材
处理：论点阐述 → 案例引用 → 数据支撑 → 逻辑串联
输出：完整内容脚本
```

#### 节点4：素材准备
```
输入：内容主题
处理：图片收集 / 视频剪辑 / 音乐选择
输出：素材包
```

#### 节点5：结尾引导
```
输入：内容核心
处理：总结提炼 → 互动引导 → 关注引导
输出：结尾文案
```

### 输出格式
```json
{
  "workflow_type": "knowledge_education",
  "nodes": ["选题策划", "钩子设计", "内容展开", "素材准备", "结尾引导"],
  "estimated_time": "30-60分钟",
  "difficulty": "medium"
}
```

```
输入：卖点 + 使用场景
处理：场景描述 → 画面构建 → 情感代入
输出：场景化内容
```

#### 节点6：行动引导
```
输入：内容主体
处理：购买引导 → 链接植入 → 优惠说明
输出：CTA文案
```

#### 节点7：紧迫制造
```
输入：行动引导
处理：限时设置 → 名额限制 → 优惠强调
输出：紧迫感设计
```

## 工作流选择指南

### 按内容类型选择

| 内容类型 | 推荐工作流 | 优先级 |
|---------|-----------|-------|
| 知识讲解 | 知识科普类 | P0 |
| 技能分享 | 教程步骤类 | P0 |
| 商品推荐 | 产品种草类 | P0 |
| 产品测评 | 对比测评类 | P1 |
| 情感表达 | 情感共鸣类 | P1 |
| 短剧创作 | 剧情演绎类 | P1 |

### 按难度选择

| 难度 | 推荐工作流 |
|------|-----------|
| 简单 | 教程步骤类 |
| 中等 | 知识科普类、情感共鸣类 |
| 复杂 | 产品种草类、对比测评类、剧情演绎类 |

### 按时间选择

| 时间 | 推荐工作流 |
|------|-----------|
| <30分钟 | 教程步骤类 |
| 30-60分钟 | 知识科普类、情感共鸣类 |
| >60分钟 | 产品种草类、对比测评类、剧情演绎类 |
