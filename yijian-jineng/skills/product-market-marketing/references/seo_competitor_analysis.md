# 竞品分析

## 基本信息
- **英文原名**: competitor-analysis
- **所属项目**: seo-geo-claude-skills
- **核心能力**: 分析竞争对手SEO/GEO——关键词、内容、反链、AI引用、流量份额差距。涵盖竞品分析和竞争对手研究。

## 快速开始

```
分析[竞争对手URL]的SEO策略
```

```
将我网站[URL]与[竞争对手1]、[竞争对手2]、[竞争对手3]对比
```

## 技能合同

**预期输出**：优先级竞争对手简报和可重用摘要。

## 工作流程

当用户请求竞品分析时：

### 步骤1：识别竞争对手
如果用户未命名，分离直接竞争对手、间接替代品和内容竞争对手。

### 步骤2：收集竞品数据
捕获URL、域名年龄、估计流量、域名权威、业务模式、目标受众和主要产品。

### 步骤3：分析关键词排名
记录总排名、前10/前3数量、高价值关键词、意图组合和关键词差距。

### 步骤4：审计内容策略
审查内容量、热门内容、发布模式、主题和成功因素。

### 步骤5：分析反链档案
审查反链总数、质量组合、顶级链接域名、链接获取模式和可链接资产。

### 步骤6：技术SEO评估
评估Core Web Vitals、移动友好性、架构、内部链接、URL结构和突出优势/弱点。

### 步骤7：GEO / AI引用分析
测试哪些查询引用竞争对手、什么格式被引用以及竞争对手在哪里仍有空缺。

### 步骤8：综合竞品情报
交付执行摘要、对比表、CITE对比、可学习优势、可利用弱点、关键词机会、内容建议和立即/短期/长期计划。

## 高级分析类型

### 内容差距分析
```
显示[竞争对手]有而我没有的内容，按流量潜力排序
```

### 链接交叉
```
查找链接到[竞争对手1]和[竞争对手2]但未链接到我的网站
```

### SERP特征分析
```
竞争对手赢取哪些SERP特征？（精选片段、PAA等）
```

### 历史跟踪
```
[竞争对手]过去一年的SEO策略如何演变？
```
