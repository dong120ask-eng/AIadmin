# 输出格式规范

## 概述

本规范定义了爆款内容流水线输出的标准格式，包括拆解报告、工作流配置和创作指南的模板结构。

---

## 输出文件清单

```
输出目录/
├── 拆解报告.md           # 完整的分析报告
├── 工作流配置.json       # 可执行的工作流配置
└── 创作指南.md           # 创作执行指南
```

## 工作流配置格式

### JSON结构

```json
{
  "workflow_name": "工作流名称",
  "version": "1.0",
  "created_at": "YYYY-MM-DD HH:mm:ss",
  "description": "工作流描述",
  
  "workflow_type": "视频拆解|产品逆向|内容创作",
  
  "input": {
    "type": "video_link|image_batch|text_description",
    "source": "抖音|小红书|视频号|截图|描述"
  },
  
  "nodes": [
    {
      "node_id": "node_001",
      "name": "节点名称",
      "type": "input|process|output|condition",
      "description": "节点描述",
      "inputs": ["依赖节点ID"],
      "outputs": ["输出变量"],
      "config": {
        "model": "使用的模型",
        "temperature": 0.7,
        "max_tokens": 2000
      },
      "prompt_template": "节点执行的提示词模板"
    }
  ],
  
  "connections": [
    {
      "from": "node_001",
      "to": "node_002",
      "condition": null
    }
  ],
  
  "output": {
    "files": [
      {
        "name": "输出文件名",
        "format": "markdown|json|html",
        "path": "保存路径"
      }
    ],
    "display": true
  }
}
```

### 扣子工作流格式

```json
{
  "nodes": [
    {
      "id": "start",
      "type": "start",
      "next": "input_node"
    },
    {
      "id": "input_node",
      "type": "LLM",
      "model": "doubao-pro",
      "prompt": "你是一个视频拆解专家...",
      "next": "analysis_node"
    },
    {
      "id": "analysis_node",
      "type": "LLM",
      "model": "doubao-pro",
      "prompt": "基于以上信息，进行深度分析...",
      "next": "workflow_node"
    },
    {
      "id": "workflow_node",
      "type": "LLM",
      "model": "doubao-pro",
      "prompt": "生成可复用的工作流配置...",
      "next": "guide_node"
    },
    {
      "id": "guide_node",
      "type": "LLM",
      "model": "doubao-pro",
      "prompt": "生成创作执行指南...",
      "next": "end"
    },
    {
      "id": "end",
      "type": "end"
    }
  ]
}
```

## 命名规范

### 文件命名
```
{类型}-{日期}-{序号}.{扩展名}

示例：
- 拆解报告-20260422-001.md
- 工作流配置-20260422-001.json
- 创作指南-20260422-001.md
```

### 变量命名
```
命名规则：小写字母 + 下划线

示例：
- video_analysis_report
- workflow_config_json
- creation_guide_md
```
