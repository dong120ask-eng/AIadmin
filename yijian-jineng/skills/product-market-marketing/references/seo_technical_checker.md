# 技术SEO检查器

## 基本信息
- **英文原名**: technical-seo-checker
- **所属项目**: seo-geo-claude-skills
- **核心能力**: 技术SEO审计——Core Web Vitals、爬取、索引、移动、速度、架构、重定向。涵盖技术SEO检查和网站速度优化。

## 快速开始

### 完整技术审计
```
对[URL/域名]执行技术SEO审计
```

### 特定问题检查
```
检查[URL]的Core Web Vitals
```

```
审计[域名]的可爬取性和索引性
```

### 迁移前审计
```
审计将[旧域名]迁移到[新域名]的技术SEO清单
```

迁移流程有6个阶段（基线快照、风险地图、重定向地图、预发QA、切换检查清单、T+1/T+7/T+30差异）。

### LLM爬虫处理
```
审计我的网站如何处理AI爬虫——我想允许检索但阻止训练
```

截至2026年，robots.txt必须对AI引擎做出明确决定。

## 工作流程

### 1. 审计可爬取性
审查robots.txt、站点地图发现、爬取浪费、重定向链和孤立模式。

### 2. 审计索引性
验证覆盖率、阻止者（noindex、X-Robots、robots.txt、规范）、重复信号和4xx/5xx失败。

### 3. 审计网站速度和Core Web Vitals
评估LCP/INP/CLS及支持指标、资源权重和最高影响修复。

### 4. 审计移动友好性
检查视口设置、布局适配、点击目标和移动优先对等。

### 5. 审计安全与HTTPS
确认SSL健康、HTTPS强制、混合内容、HSTS和安全头。

### 6. 审计URL结构
检查URL模式、参数、大小写一致性和重定向卫生。

### 7. 审计结构化数据
验证schema、映射缺失机会并注明CORE-EEAT影响。

### 8. 审计国际SEO（如适用）
验证hreflang、返回标签、区域定位和x-default。

### 9. 生成技术审计摘要
将发现汇总为记分卡、优先级队列、快速见效、路线图和监控计划。

## 示例

**用户**："检查cloudhosting.com的技术SEO"

**输出**（简略）：312页爬取；`robots.txt`通配符`Disallow: /*?`阻止分面产品页面（P0）；站点地图缺少47个URL；7个规范冲突；Core Web Vitals LCP 4.2s需要降至<2.5s。

## 成功秘诀

1. **按影响优先级** — 首先修复阻塞索引和收入风险
2. **持续监控** — 使用搜索控制台警报和CWV跟踪
3. **测试更改** — 广泛推广前验证修复
4. **记录一切** — 跟踪差异、负责人和验证日期
5. **定期审计** — 每季度或重大发布前重新检查
