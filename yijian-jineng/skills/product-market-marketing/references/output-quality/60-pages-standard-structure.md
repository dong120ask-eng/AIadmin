## 二、数据可视化强制规则

### 2.1 数据类型与图表一一对应

| 数据类型 | 强制使用图表 | 示例 |
|---------|-------------|------|
| 时间趋势数据 | 折线图（带数据标签） | 2022-2026年行业市场规模增长趋势 |
| 分类对比数据 | 柱状图（横向/纵向） | 各渠道获客成本对比、竞品粉丝数对比 |
| 占比数据 | 饼图/环形图 | 预算分配占比、内容类型占比 |
| 流程数据 | 流程图（带箭头和步骤） | 用户决策路径、内容生产流程 |
| 漏斗数据 | 漏斗图（带转化率） | 流量转化漏斗、用户生命周期漏斗 |
| 矩阵数据 | 四象限矩阵图 | 渠道优先级矩阵、风险评估矩阵 |
| 对比数据 | 雷达图 | 竞品综合实力对比、产品卖点对比 |
| 优先级数据 | 热力图 | 用户痛点优先级、内容选题优先级 |
| 时间计划数据 | 甘特图/日历表 | 3个月执行计划、90天内容排期 |

### 2.2 图表设计强制标准

1. **所有图表必须添加清晰的标题和数据标签，数据标签保留1位小数**
2. **图表配色严格使用统一体系**：
   - 主色：#165DFF（商务蓝）
   - 辅助色：#FF7D00（橙色）
   - 中性色：#F5F7FA（浅灰）
3. **去掉所有多余的网格线、边框、背景色，保持图表简洁干净**
4. **所有图表比例统一为16:9，与PPT页面比例一致**
5. **复杂图表必须添加简短的图表说明，解释核心结论**
6. **同一类数据使用同一种图表类型，保持全案视觉统一**

## 三、配图精准匹配强制规则

### 3.1 配图内容匹配规则

| 页面内容 | 必须使用的配图类型 | 禁止使用的配图 |
|---------|-------------------|---------------|
| 产品分析 | 产品高清实景图、产品细节图、产品使用场景图 | 随便放的商务图、握手图、开会图 |
| 用户洞察 | 真实用户生活场景图、用户使用产品场景图 | 卡通人物、模特图、抽象图 |
| 竞品分析 | 竞品产品截图、竞品账号截图、竞品内容截图 | 通用互联网图、科技感抽象图 |
| 流量分析 | 平台logo图、渠道界面截图、数据仪表盘示意图 | 随便放的箭头图、流程图 |
| 内容策略 | 爆款内容截图、视频封面截图、笔记封面截图 | 通用写作图、键盘图 |
| 直播带货 | 真实直播场景图、直播间界面截图、产品展示图 | 卡通直播图、抽象带货图 |
| 私域运营 | 企业微信界面截图、微信群界面截图、朋友圈截图 | 通用社交图、手机图 |
| AI营销 | AI搜索结果截图、大模型界面截图、问答界面截图 | 通用AI图、机器人图 |

### 3.2 配图质量强制标准

1. **所有配图分辨率≥300dpi，无水印、无版权问题**
2. **配图风格统一为写实商务风，禁止使用卡通风、手绘风、赛博朋克风**
3. **配图亮度、对比度统一，避免过暗或过亮**
4. **每页PPT配图数量控制在1-2张，最多不超过3张**
5. **配图与文字左右分栏排版，文字占比≤50%，配图占比≥50%**
6. **所有配图必须添加简短的图注，说明配图内容**

## 五、文件输出规范

### 5.1 三种格式同步输出

**1. Markdown源文件**
- 文件命名：`[产品名称]-营销全案-源文件.md`
- 完整保留所有章节结构、标题层级、列表、表格
- 自动生成目录
- 所有图表和配图添加占位符和说明

**2. 可编辑PPT文件**
- 文件命名：`[产品名称]-营销全案-可编辑PPT.pptx`
- 严格按照60页架构生成
- 所有元素均可编辑
- 自动添加母版、页码、页眉、页脚

**3. 高清PDF文件**
- 文件命名：`[产品名称]-营销全案-最终交付版.pdf`
- 完美保留所有格式、图表、配图、超链接
- 自动生成目录和书签
- 自动压缩文件大小
