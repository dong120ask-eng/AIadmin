采用「底层能力→框架模板→工作流程→全案交付→可视化输出」的五层架构，层层递进，确保每一步都可落地、可追溯，避免断层。

# 三、8大工作流详解（实操导向， step by step ）

每个工作流均包含「触发话术+执行步骤+交付物+核心价值」，无需猜测，输入话术即可启动，全程自动化执行，明确每一步输出结果。

## 工作流1：前期调研诊断（奠定基础，找准方向）

### 核心目标

快速摸清市场、竞品、用户核心情况，解决「市场有多大、对手在做什么、用户真正要什么」的核心问题，为后续策略提供数据支撑。

### 触发话术（直接复制使用）

- 帮我做【XX行业/品类】的行业调研
- 帮我拆解【XX竞品】的深度分析报告
- 帮我做【XX产品】的目标用户画像
- 帮我输出【XX品类】的用户痛点地图

### 标准化执行步骤（自动执行，无需干预）

```
步骤1：行业与市场分析（PEST分析+市场规模+趋势预判）
步骤2：竞品深度拆解（3个核心竞品+5个潜在竞品，全维度对标）
步骤3：用户洞察与画像（3类核心用户+2类边缘用户，精准刻画）
步骤4：痛点地图输出（筛选核心痛点，明确需求优先级）
```

### 交付物（清晰可查，直接使用）

- 行业白皮书（含市场数据、趋势分析、机会与风险）
- 竞品深度拆解报告（含产品、流量、内容、转化全维度对比）
- 3类核心用户画像（含年龄、性别、消费力、痛点、决策路径）
- 用户痛点地图（可视化呈现痛点优先级、解决方案对应关系）

## 工作流2：营销战略规划（顶层设计，明确方向）

### 核心目标

确定品牌/产品的市场定位、品牌策略、定价方案，搭建营销战略框架，确保后续所有执行动作都围绕核心目标展开，避免盲目投入。

### 触发话术（直接复制使用）

- 帮我做【XX品牌/产品】的市场定位
- 帮我制定【XX品牌】的年度品牌策略
- 帮我规划【XX产品】的定价方案
- 帮我制定【XX项目】的年度营销规划

### 标准化执行步骤

```
步骤1：市场定位分析（竞争图谱+商战策略+定位陈述，找准差异化）
步骤2：用户洞察深化（基于前期调研，补充用户心理触点、助推策略）
步骤3：品牌策略设计（价值曲线+超级符号+五感体系，强化品牌记忆）
步骤4：定价策略制定（成本测算+竞品对标+用户感知，确定最优定价）
```

### 详细执行说明（补充细节，提升落地性）

| 步骤 | 调用模块 | 输入要求 | 输出结果 |
|------|----------|----------|----------|
| 市场定位分析 | 模块1（战略定位类） | 行业/品类/竞品基础信息 | 《市场定位分析报告》（含竞争图谱、商战策略、定位陈述） |
| 用户洞察深化 | 模块2（用户行为类） | 目标人群基础描述 | 《用户洞察分析报告》（含决策旅程、心理触点、助推策略） |
| 品牌策略设计 | 模块3（品牌战略类） | 定位陈述+用户洞察结果 | 《品牌策略设计报告》（含价值曲线、超级符号、五感体系） |
| 定价策略制定 | 模块7（定价策略类） | 产品成本+竞品价格+用户感知 | 《定价策略方案》（含价格测试、策略选择、呈现优化） |

### 推荐组合打法（落地性强化）

先软后硬，循序渐进：小红书软性种草（1-4周，建立信任）→ B站专业测评（2-6周，强化权威）→ 抖音痛点解决+直播带货（8-12周，驱动转化），形成完整种草-转化闭环。


搭建全平台种草内容矩阵，结合硬性种草（即时转化）和软性种草（建立信任），实现「短期转化+长期品牌建设」双目标，覆盖用户全决策链路。

### 触发话术（直接复制使用）

- 帮我写【XX产品】的种草文案（硬性/软性）
- 帮我做【XX品牌】的全平台种草内容矩阵
- 帮我规划【XX产品】的种草节奏（蓄水-加速-收割）

### 种草双引擎（清晰区分，按需匹配）

| 维度 | 硬性种草（即时转化） | 软性种草（建立信任） |
|------|---------------------|---------------------|
| 核心目标 | 驱动用户立即下单，提升短期转化 | 建立品牌信任，驱动用户主动搜索、长期复购 |
| 内容比例 | 50%产品信息 + 50%痛点/场景（直接关联产品） | 70%价值内容 + 30%产品露出（不硬推，潜移默化种草） |
| 典型结尾 | 引导行动（点击左下角、现在下单、直播间抢购） | 不引导购买，传递价值，让用户自主决策 |
| 效果周期 | 1-7天（短期见效） | 1-12个月（长期沉淀） |
| 适配平台 | 抖音、快手、小红书（挂车/直播） | B站、知乎、小红书（干货/科普） |

### 核心种草框架（全行业通用，直接套用）

#### 硬性种草12种框架（聚焦转化）

- 抖音6种：痛点解决型、场景代入型、对比测评型、教程干货型、情绪共鸣型、权威背书型
- 小红书6种：好物分享型、使用教程型、避坑指南型、成分党型、生活记录型、专业测评型

#### 软性种草22种框架（聚焦信任）

- 短视频5种 + 小红书5种 + 文章6种 + B站6种（适配各平台调性，传递价值）

### 标准化执行步骤

```
步骤1：种草类型决策（根据商业目标，确定硬性/软性/混合策略）
步骤2：框架选型（自动匹配适配产品/平台的种草框架）
步骤3：核心素材库构建（提炼产品核心卖点、用户痛点、场景素材）
步骤4：批量内容生产（生成多平台适配的种草内容，避免重复创作）
步骤5：跨平台适配（按各平台规则微调，确保内容合规、适配）
```

### 推荐种草节奏（科学规划，循序渐进）

- 蓄水期（1-4周）：以软性种草为主，发布干货、科普内容，建立品牌信任，积累初始流量
- 加速期（4-8周）：扩大软性种草覆盖，新增少量硬性种草，测试转化效果，优化内容方向
- 收割期（8-12周）：加大硬性种草比例，结合直播、挂车，驱动用户下单，完成转化闭环

#### 4. 活动策划（引爆流量，提升转化）

## 生成规则（强制执行，确保笔记质量）

### 标题要求（适配小红书算法，提升点击率）

- 字数：15-20字（适配小红书标题显示规则，不截断）
- 核心要素：必须包含1个核心关键词 + 1个情绪词（如"谁懂啊""救命""狂喜"）
- 技巧：多用感叹号、问号、数字，加入对比、反差，提升吸引力

### 正文要求（提升阅读体验，促进互动）

- 总字数：300-500字（不长不短，适合碎片化阅读）
- 排版：每段≤3行，多空行，适当使用emoji（每段1-2个，不堆砌）
- 开头：黄金3秒，必须直击痛点或抛出悬念，留住用户
- 结尾：有明确引导（评论区交流、收藏、尝试、搜索），提升互动率
- 语气：口语化、闺蜜感，无广告腔、无官方话术，真实自然

### 标签要求（精准引流，提升曝光）

- 数量：10-15个（不多不少，适配小红书算法）
- 组成：1个大品类标签 + 3个中品类标签 + 5个长尾标签 + 3个热门标签 + 2个品牌标签（按热度排序）
- 技巧：标签自然贴合内容，不堆砌无关标签，提升搜索排名

### 合规要求（避免违规，确保笔记正常曝光）

- 禁止使用极限词（最、第一、特效、根治等）
- 禁止使用医疗术语（治疗、疗效等，改为"缓解""改善"）
- 禁止虚假宣传，所有效果必须真实可信
- 禁止出现联系方式、二维码、外链等违规内容
