## 一、爆款文案核心方法论

### 1.1 核心三要素公式
```
爆款概率 P = 0.35E + 0.45V + 0.2I

E = 情感钩子强度（1-5分）
V = 价值密度（技巧数量/字数）
I = 互动触发点数量

当 P > 0.8 时，笔记进入爆款候选池
```

### 1.2 用户行为数据（2026年）
| 指标 | 数据 | 应对策略 |
|------|------|---------|
| 注意力窗口 | 8秒 | 开篇50字内建立价值承诺 |
| 完播率权重 | 40% | 前3秒必须展示核心信息 |
| 真实感缺失跳出 | 72% | 原相机实拍+坦诚不完美 |
| 段落跳出阈值 | 150字 | 每段控制在80-120字 |

## 二、11种爆款文案框架详解

### 🔴 硬性转化型（6种）

#### 1. 痛点解决型（首选，转化率最高）

**适用场景**：所有解决具体痛点的产品

**核心结构**：
```
痛点暴击 → 产品出现 → 使用体验 → 效果展示 → 总结推荐
```

**标题公式**：
- 谁懂啊！被XX问题折磨了N年，终于被它救了！
- 救命！XX问题终于有解了！

**正文模板**：
```
谁懂啊家人们！[具体痛点描述，越细节越好]
试了无数方法都没用，差点放弃了...
直到被闺蜜按头安利了这个[产品名]！

第一次用就惊了！[使用体验]
才用了[时间]，[具体效果展示，要有数据]

现在我逢人就夸！[总结推荐]
真心建议所有[目标人群]都去试试！
```

**封面建议**：左右对比图（使用前vs使用后），大字标题写核心痛点

**完整示例（恩纳乳膏）**：
```
标题：谁懂啊！纹身疼到哭的人，终于找到救星了！

正文：
谁懂啊家人们！上次纹个小纹身疼到我全程攥紧拳头，眼泪直流，纹完胳膊肿了三天...
本来都不敢再纹了，直到被纹身师安利了这个恩纳乳膏！

提前半小时厚涂一层，裹上保鲜膜，纹的时候真的一点都不疼！
就只有一点点麻麻的感觉，全程轻松玩手机，纹完也没有红肿

现在我逢人就夸！已经安利了三个姐妹去纹身了，都说完全不疼！
真心建议所有怕疼的姐妹，纹身、纹眉、打耳洞之前一定要涂它！几十块的快乐，再也不用疼到怀疑人生✅

#恩纳乳膏 #纹身麻药 #怕疼星人 #纹身不疼 #纹眉必备 #外用麻药 #好物分享 #纹身日记
```

## 四、配图质量强制标准

### 4.1 基础参数
```
比例：3:4（小红书竖版）
分辨率：1080×1440
格式：JPG
大小：≤5MB
```

### 4.2 光线要求
- 优先自然光（窗边光、上午10点/下午4点阳光）
- 柔和不刺眼，无明显阴影
- 避免闪光灯直射

### 4.3 构图要求
- 主体居中，占画面60%以上
- 上下左右各留10%留白
- 背景干净简洁（白色、米色、木质背景最佳）

### 4.4 色彩要求
- 暖色调为主
- 饱和度适中，对比度适中
- 禁止高饱和荧光色

### 4.5 细节要求
- 无水印、无文字、无logo
- 无多余杂物
- 加入轻微的手机拍摄颗粒感
- 避免过度锐化和磨皮
