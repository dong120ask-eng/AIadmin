# GEO审计编排

## 基本信息
- **英文原名**: geo-audit
- **所属项目**: geo-seo-claude
- **核心能力**: 全网站GEO+SEO审计，通过并行子代理委托协调跨AI可引用性、平台分析、技术基础设施、内容质量和Schema标记的全面生成式引擎优化审计。生成综合GEO评分（0-100）及优先级行动计划。

## 目的

本技能对任何网站执行全面的生成式引擎优化（GEO）审计。GEO是优化网页内容以使AI系统（ChatGPT、Claude、Perplexity、Gemini等）能够发现、理解、引用和推荐的做法。该审计衡量网站在所有GEO维度上的表现，并生成可执行的改进计划。

## 核心洞察

传统SEO优化搜索引擎排名。GEO优化AI引用和推荐。在GEO指标上得分高的网站在AI生成响应中的可见度提高30-115%（佐治亚理工/普林斯顿/IIT德里2024年研究）。两个学科有重叠但有不同的要求。

## 审计工作流程

### 阶段1：发现与侦察

**步骤1：获取首页并检测业务类型**

1. 使用WebFetch检索首页URL。
2. 提取以下信号：
   - 页面标题、元描述、H1标题
   - 导航菜单项（揭示网站结构）
   - 页脚内容（揭示商业信息、位置、法律页面）
   - 首页Schema.org标记（Organization、LocalBusiness等）
   - 定价页面链接（SaaS指标）
   - 产品列表模式（电商指标）
   - 博客/资源部分（发布商指标）
   - 服务页面（代理商指标）
   - 地址/电话/Google地图嵌入（本地业务指标）

3. 使用这些模式分类业务类型：

| 业务类型 | 检测信号 |
|---|---|
| **SaaS** | 定价页面、"注册"/"免费试用"CTA、app.domain.com子域、功能对比表、集成页面 |
| **本地企业** | 首页上的实体地址、Google地图嵌入、"附近"内容、LocalBusiness schema、服务区域页面 |
| **电商** | 产品列表、购物车、产品schema、类别页面、价格展示、"加入购物车"按钮 |
| **发布商** | 博客重导航、文章schema、作者页面、基于日期的存档、RSS源、高内容量 |
| **代理商/服务** | 案例研究、作品集、"我们的工作"部分、团队页面、客户logo、服务描述 |
| **混合型** | 以上信号的组合——按主导模式分类 |

**步骤2：爬取站点地图和内部链接**

1. 尝试获取 `/sitemap.xml` 和 `/sitemap_index.xml`。
2. 如果站点地图存在，按以下优先级提取最多50个唯一页面URL：
   - 首页（始终包含）
   - 顶级导航页面
   - 高价值页面（定价、关于、联系、关键服务/产品页面）
   - 博客文章（样本5-10个最新）
   - 类别/着陆页
3. 如果没有站点地图，从首页爬取内部链接：
   - 提取指向同一域的所有`<a href>`链接
   - 深度跟随最多2层
   - 优先从主导航链接的页面
4. 遵守robots.txt指令——不抓取禁止的路径。
5. 强制限制最多50页，每次抓取30秒超时。

**步骤3：收集页面级数据**

对于爬集中的每个页面，记录：
- URL、标题、元描述、规范URL
- H1-H6标题结构
- 主内容字数
- 存在的Schema.org类型
- 内部/外部链接数
- 有/无alt文字的图片
- Open Graph和Twitter Card元标签
- 响应状态码
- 页面是否有结构化数据

### 阶段2：并行子代理委托

委托分析给5个专业子代理。每个子代理基于收集的页面数据运行并生成类别评分（0-100）及发现。

**子代理1：AI可见性分析**
- 分析内容块的AI可引用性（可引用性评分）
- 通过robots.txt和llms.txt检查AI爬虫访问
- 扫描YouTube、Reddit、Wikipedia、LinkedIn上的品牌存在
- 对AI用于实体识别的品牌权威信号评分

**子代理2：平台优化**
- 评估Google AI Overviews、ChatGPT、Perplexity、Gemini、Bing Copilot的就绪程度
- 检查平台特定的排名因素和优化机会

**子代理3：技术GEO基础设施**
- 分析robots.txt中的AI爬虫访问
- 验证AI系统的元标签、头部和技术可访问性
- 检查页面速度、服务器端渲染和Core Web Vitals
- 评估安全头部和移动优化

**子代理4：内容E-E-A-T质量**
- 评估经验、专业、权威、可信度信号
- 检查作者简历、资质、来源引用
- 评估内容新鲜度、深度和原创性
- 验证"关于"页面质量和团队资质

**子代理5：Schema与结构化数据**
- 验证所有schema.org标记
- 检查GEO关键schema类型（FAQ、HowTo、Organization、Product、Article）
- 评估schema完整性和准确性
- 识别缺失的schema机会

### 阶段3：评分聚合与报告生成

#### 综合GEO评分计算

总体GEO评分（0-100）是六个类别评分的加权平均值：

| 类别 | 权重 | 衡量内容 |
|---|---|---|
| **AI可引用性** | 25% | 内容对AI系统的可引用/可提取程度 |
| **品牌权威** | 20% | 第三方提及、实体识别信号 |
| **内容E-E-A-T** | 20% | 经验、专业、权威、可信度 |
| **技术GEO** | 15% | AI爬虫访问、llms.txt、渲染、速度 |
| **Schema与结构化数据** | 10% | Schema.org标记质量和完整性 |
| **平台优化** | 10% | AI模型训练和引用的平台存在 |

**公式：**
```
GEO_Score = (可引用性 * 0.25) + (品牌 * 0.20) + (E-E-A-T * 0.20) + (技术 * 0.15) + (Schema * 0.10) + (平台 * 0.10)
```

#### 评分解读

| 评分范围 | 等级 | 解读 |
|---|---|---|
| 90-100 | 优秀 | 顶级GEO优化；网站极有可能被AI引用 |
| 75-89 | 良好 | 强大的GEO基础，有改进空间 |
| 60-74 | 一般 | 中等GEO存在；存在重大优化机会 |
| 40-59 | 较差 | 较弱的GEO信号；AI系统可能难以引用或推荐 |
| 0-39 | 危急 | 最小的GEO优化；网站对AI系统基本不可见 |

## 问题严重性分类

### 危急（立即修复）
- robots.txt中阻止所有AI爬虫
- 没有可索引内容（仅JavaScript渲染无SSR）
- 域级noindex指令
- 关键页面返回5xx错误
- 完全缺少任何结构化数据
- 品牌不被任何AI系统识别为实体

### 高优先级（1周内修复）
- 阻止关键AI爬虫（GPTBot、ClaudeBot、PerplexityBot）
- 没有llms.txt文件
- 关键页面上零问答内容块
- 缺少Organization或LocalBusiness schema
- 内容页面没有作者署名
- 所有内容在登录/付费墙后面没有预览

### 中优先级（1月内修复）
- 部分AI爬虫阻止（一些允许，一些阻止）
- llms.txt存在但不完整或格式错误
- 内容块平均引用评分低于50
- 有FAQ内容的页面缺少FAQ schema
- 作者简历单薄没有资质
- 没有Wikipedia或Reddit品牌存在

### 低优先级（可能时优化）
- 轻微schema验证错误
- 部分图片缺少alt文字
- 非关键页面的内容新鲜度问题
- 缺少Open Graph标签
- 部分页面标题层次结构不理想
- LinkedIn公司页面存在但不完整

## 业务类型特定审计调整

### SaaS网站
- 额外权重：功能对比表（高可引用性）、集成页面、文档质量
- 检查：API文档结构、更新日志页面、知识库组织
- 关键schema：SoftwareApplication、FAQPage、HowTo

### 本地企业
- 额外权重：NAP一致性、Google商家资料信号、本地schema
- 检查：服务区域页面、位置特定内容、评论标记
- 关键schema：LocalBusiness、GeoCoordinates、OpeningHoursSpecification

### 电商网站
- 额外权重：产品描述（可引用性）、对比内容、购买指南
- 检查：产品schema完整性、评论聚合、产品页面FAQ部分
- 关键schema：Product、AggregateRating、Offer、BreadcrumbList

### 发布商
- 额外权重：文章质量、作者资质、来源引用实践
- 检查：Article schema、作者页面、发布日期新鲜度、原创研究
- 关键schema：Article、NewsArticle、Person（作者）、ClaimReview

### 代理商/服务
- 额外权重：案例研究（可引用性）、专业展示、思想领导力
- 检查：作品集schema、团队资质、行业特定专业信号
- 关键schema：Organization、Service、Person（团队）、Review

## 扣子部署建议

### 推荐插件
- **网页爬虫插件**：用于获取和分析网站内容
- **必应搜索插件**：用于检查搜索引擎索引状态
- **浏览器插件**：用于渲染JavaScript内容

### 适用场景
- SEO代理机构为客户进行网站审计
- 企业市场部门评估自身AI搜索可见性
- 内容营销团队识别优化机会
- 技术团队了解技术SEO和GEO需求

### 典型工作流程
```
用户输入URL → 自动发现 → 5个并行分析 → 评分聚合 → 生成报告
```

- 总体GEO评分（0-100）
- 6个维度的详细评分
- 危急/高/中/低优先级问题清单
