# 产品分析报告模板 V2.0（专业版）

## 核心要求

### 输出标准
- **格式**：PDF（A4）
- **页数**：15-25页
- **风格**：咨询公司提案级别
- **必须有**：数据可视化图表、信息图、专业排版

### 视觉规范

| 用途 | 色值 | 说明 |
|-----|------|------|
| 主色 | #2E5C8A | 深蓝，专业 |
| 强调色 | #27AE60 | 绿色，优势 |
| 警示色 | #E74C3C | 红色，风险 |
| 辅助色 | #3498DB | 浅蓝，图表 |
| 背景 | #F8F9FA | 浅灰 |

---

## 必须包含的图表

### 第1页：封面
- 产品主图（占页面40%）
- 品牌名称+报告标题
- 日期、版本、版权

### 第2页：执行摘要
- 核心数据大字展示
- 3-5个结论卡片
- 一页纸总结

### 第3-5页：市场分析
**图表1：市场规模柱状图**
- 近5年市场规模数据
- 标注CAGR增长率
- 预测趋势线

**图表2：市场份额饼图**
- 各品牌占比
- 渠道分布

**图表3：增长趋势折线图**
- 年度增长趋势
- 预测数据

### 第6-8页：竞品分析
**图表4：竞品对比雷达图**
- 5-6维度对比
- 本产品突出显示

**图表5：对比柱状图**
- 各维度得分
- 优势可视化

**图表6：竞品SWOT矩阵**

### 第9-11页：用户画像
**图表7：年龄分布饼图**
**图表8：地域分布柱状图**
**图表9：消费行为信息图**

### 第12-14页：产品分析
**图表10：定位金字塔图**
**图表11：核心卖点信息图**
**图表12：优势对比图**

### 第15-16页：SWOT分析
**图表13：SWOT四象限矩阵**（占页面60%）

### 第17-18页：策略建议
**图表14：执行路线图**

## 图表生成方法

### 使用echart技能生成
在PDF生成前，先用echart生成图表PNG：

```
1. 市场规模柱状图 → market_size.png
2. 市场份额饼图 → market_share.png
3. 竞品对比雷达图 → competitor_radar.png
4. 年龄分布饼图 → age_distribution.png
5. SWOT矩阵 → swot_matrix.png
```

### 图表风格要求
- 统一配色方案
- 清晰的数据标注
- 专业的图例说明
- 高清输出（300dpi）

## PDF生成流程

```
Step 1: 收集产品数据
Step 2: 使用echart生成图表
Step 3: 使用Python ReportLab生成PDF
Step 4: 嵌入图表图片
Step 5: 质量检查
```
