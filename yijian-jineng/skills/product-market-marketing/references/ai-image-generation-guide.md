# AI图片生成指南

## 核心能力

### 支持直接生成的图片类型

| 图片类型 | 数量 | 尺寸要求 | 用途 |
|---------|------|---------|------|
| 电商主图 | 10张 | **800×800px（正方形）** | 淘宝/京东/抖音商品主图，必须正方形 |
| 详情页图片 | 8张 | **750×1000px 或 750×N px** | 商品详情页各板块，宽度固定750px |
| 社交媒体图 | 按需 | 1080×1920px / 1080×1080px | 小红书/抖音封面 |

### 重要尺寸规范

**电商主图必须遵循各平台规范**：

| 平台 | 主图尺寸 | 格式 | 文件大小 | 备注 |
|-----|---------|------|---------|------|
| 淘宝/天猫 | **800×800px** | JPG/PNG | ≤3MB | 正方形，支持放大镜功能需≥800px |
| 京东 | **800×800px** | JPG/PNG | ≤1MB | 正方形，白底优先 |
| 抖店（抖音电商） | **800×800px** | JPG/PNG | ≤5MB | 正方形，支持1:1展示 |
| 拼多多 | **750×750px** | JPG/PNG | ≤1MB | 正方形，白底优先 |
| 小红书 | **1242×1242px** | JPG/PNG | ≤20MB | 正方形，3:4竖图也可 |

**详情页规范**：

| 平台 | 详情页宽度 | 推荐高度 | 格式 | 备注 |
|-----|-----------|---------|------|------|
| 淘宝/天猫 | **750px** | 800-2000px/张 | JPG | 高度自适应 |
| 京东 | **750px** | 800-2000px/张 | JPG | 总高度≤30000px |
| 抖店 | **750px** | 800-1500px/张 | JPG | 每张≤2MB |
| 拼多多 | **750px** | 800-1500px/张 | JPG | 总图片≤20张 |
| 小红书 | **1242px** | 按需 | JPG | 图文笔记配图 |

**生成图片时的强制要求**：
1. 电商主图必须生成**正方形**（1:1比例）
2. 主图推荐尺寸：**800×800px**（通用适配所有平台）
3. 详情页宽度固定：**750px**
4. 输出格式：JPG（质量85%以上）
5. 白底或浅色背景优先（大部分平台要求）

### 图片生成时机

```
产品录入 → 卖点挖掘 → 关键词生成 → 电商物料文案生成 → 【图片生成】→ 合规筛查 → 成果打包
```

## Prompt构建模板

### 通用结构

```
[产品类型] + [核心内容] + [视觉风格] + [色彩基调] + [布局要求] + [合规声明区域]
```

**主图1 - 产品展示**：
```
药品包装盒正面展示图，白色药盒居中，背景纯白色，
专业产品摄影风格，光线柔和均匀，产品占据画面70%，
清晰展示品牌名称，简约高端感，底部预留合规声明文字区域
```

```
浅蓝白色调，扁平化设计风格，专业医药产品宣传感，
无人物，底部预留合规声明区域
```

## 质量控制

### 生成前检查
- [ ] Prompt是否清晰明确
- [ ] 是否包含产品核心卖点
- [ ] 是否预留合规声明区域

### 生成后检查
- [ ] 图片清晰度是否达标
- [ ] 色彩是否协调
- [ ] 是否符合品牌调性

### 重新生成标准
- 图片模糊、质量差
- 色彩严重偏离
- 布局混乱
- 出现不应该出现的元素

---

## 医药产品特殊要求

1. **必须预留合规声明区域**：画面底部预留文字区域
2. **避免过度医疗感**：温和、生活化的视觉风格
3. **不展示人体器官**：使用示意图、图解方式
4. **不生成人物肖像**：避免肖像权问题

## 批量生成执行示例

```python
# 准备产品信息
product_name = "产品名称"
core_sell = "核心卖点"

# 构建10张主图Prompt
main_image_prompts = [
    f"{product_name}产品包装盒展示，白色背景，专业摄影风格...",
    f"{product_name}核心卖点信息图，{core_sell}...",
    # ... 其他8张
]

# 循环生成
for i, prompt in enumerate(main_image_prompts, 1):
    image_generate(
        prompt=prompt,
        count=1,
        file_prefix=f"主图{i}"
    )
```
