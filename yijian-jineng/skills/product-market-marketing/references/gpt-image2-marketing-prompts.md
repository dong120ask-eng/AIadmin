# GPT-Image-2 营销配图专业提示词库

> 来源：awesome-gpt-image-2-prompts 社区精选案例
> 许可证：CC BY 4.0
> **默认使用完整中文prompt进行编写，GPT-Image-2对中文同样有出色的理解能力**

## 一、Prompt编写核心原则

### 五大原则（按优先级排序）

1. **光线优先**：先定光线类型（荧光灯/霓虹/闪光/自然光/侧光），光线决定画面质感
2. **材质质感**：必须描述皮肤纹理、布料褶皱、金属反光等材质细节
3. **构图明确**：明确镜头类型(35mm/CCD/中画幅)、视角(平视/仰拍/俯拍)、景别(特写/中景/全景)
4. **风格锚定**：用具体风格关键词锚定（胶片颗粒，柔和黑雾，镜面高光）
5. **负面提示**：必须列出排除项（无水印，无塑料感皮肤，无过度精修）

### GPT-Image-2 专属特性

| 特性 | 说明 | 提示词写法 |
|------|------|-----------|
| 像素级文字渲染 | 中文/英文/日文均达native水准 | "标题内容" verbatim |
| 跨图一致性 | 同一角色/风格在多张图保持一致 | 会话内续写 |
| 商用级插画 | 无需人工精修可直接商用 | 指定风格关键词 |
| 风格迁移 | 精确还原特定艺术风格 | "以【艺术家/风格】的风格" |

### 通用Prompt结构

```
【镜头/媒介类型】，【光线描述】，【色彩/质感】，【构图/视角】，
【主体描述：人物/物体细节】，【姿势/动作】，
【背景/环境描述】，【风格关键词】，
【质量约束】，【比例参数】
```

## 五、语言使用说明

**默认使用完整中文prompt进行编写**

GPT-Image-2对中文同样有出色的理解能力，中文prompt可以：
- 更精确地描述中国元素（汉服、水墨、国风建筑）
- 更自然地表达场景氛围和情绪
- 更清晰地指定中国传统配色和视觉元素
- 避免翻译过程中的语义损失

**可保留英文的场景**：
- 技术参数：镜头型号（35mm、85mm）、光圈值（f/1.4）
- 艺术风格名称：art deco、film noir（已是国际通用术语）
- 材质词汇：metallic、translucent（已是业界通用术语）

**混合使用示例**：
```
35毫米胶片摄影，日系小清新风格，
女孩穿着汉服站在老北京胡同里，
golden hour光线，胶片颗粒质感，
柔和虚化背景
```
