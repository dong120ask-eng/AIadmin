## 核心原则

### 设计核心逻辑

电商物料设计必须严格遵循**差异化卖点优先**原则：

```
产品差异化卖点 → 视觉转化策略 → 转化漏斗设计
```

### 核心要素

1. **差异化卖点突出**：基于 `Global_Core_Sell`（全流程唯一核心卖点）和 `Global_Assist_Sell`（3个辅助卖点）
2. **视觉冲击力强**：第一眼抓住用户注意力
3. **转化路径清晰**：引导用户从浏览到下单的完整路径
4. **平台合规**：符合各平台的设计规范和广告法要求

### 禁止事项

- ❌ 严禁使用极限词（最佳、第一、唯一等）
- ❌ 严禁虚假宣传、夸大功效
- ❌ 严禁侵权使用他人图片
- ❌ 严禁低俗、违规内容

## 电商主图生成

### 主图类型分类

#### 1. 产品展示主图（第1张）

**目标**：展示产品全貌，建立第一印象

**设计要求**：
- ✅ 产品占据画面 60-70%
- ✅ 背景简洁，突出产品
- ✅ 光线充足，细节清晰
- ✅ 拍摄角度展示产品核心外观
- ✅ 无多余装饰元素

**视觉策略**：
- 单品类：正面45度角拍摄，展示产品整体
- 套装类：展示完整套装，突出数量感
- 食品类：展示包装+内容物，突出食欲感
- 美妆类：展示产品+使用场景，突出效果感

**示例**：
```
[产品名称] + [产品全貌] + [简洁背景] + [品牌Logo]
```

#### 2. 核心卖点主图（第2张）

**目标**：展示产品核心卖点，激发购买欲望

**设计要求**：
- ✅ 突出 `Global_Core_Sell`（核心卖点）
- ✅ 使用对比图、数据图、示意图
- ✅ 文案简洁，一击即中
- ✅ 视觉层级清晰，卖点突出

**视觉策略**：
- 使用前后对比图（使用前 vs 使用后）
- 使用数据可视化图表（提升XX%、降低XX%）
- 使用示意图展示技术原理
- 使用场景图展示使用效果

**示例**：
```
[核心卖点] + [对比图/数据图] + [简短文案] + [信任背书]
```

#### 3. 细节展示主图（第3张）

**目标**：展示产品细节，建立信任感

**设计要求**：
- ✅ 展示产品工艺、材质、成分

- ✅ 配合文字说明，强化专业感
- ✅ 质感真实，无过度美化

**视觉策略**：
- 工艺细节：展示接缝、缝线、边角处理
- 材质细节：展示面料、材质纹理、质感
- 成分细节：展示配方、成分表、证书
- 功能细节：展示按钮、接口、功能部件

**示例**：
```
[细节特写] + [工艺/材质说明] + [专业背书]
```

#### 4. 使用场景主图（第4张）

**目标**：展示产品使用场景，激发代入感

**设计要求**：
- ✅ 展示产品实际使用场景
- ✅ 人物自然，表情真实
- ✅ 场景真实，无过度美化
- ✅ 氛围舒适，符合产品调性

**视觉策略**：

## 详情页生成

### 详情页结构框架

```
首屏海报 → 核心痛点 → 产品解决方案 → 核心卖点 → 使用场景 → 品牌故事 → 用户评价 → 购买引导
```

### 各板块详细设计

#### 1. 首屏海报（抓注意力）

**目标**：第一眼抓住用户，激发继续浏览的兴趣

**设计要求**：
- ✅ 产品占据画面核心位置
- ✅ 核心卖点文案醒目
- ✅ 视觉冲击力强，有美感
- ✅ 品牌Logo清晰可见

**文案策略**：
- 一句话卖点：核心卖点 + 利益点
- 副标题：补充说明，强化优势
- 行动按钮：立即购买、限时优惠

**示例**：
```
[产品大图] + [一句话卖点] + [副标题] + [立即购买按钮]
```

#### 2. 核心痛点（引发共鸣）

**目标**：激发用户痛点共鸣，建立需求

**设计要求**：
- ✅ 直击用户核心痛点
- ✅ 使用场景化描述
- ✅ 视觉共鸣，用户代入
- ✅ 语气贴近用户，真实可信

**文案策略**：
- 痛点描述：使用用户日常遇到的问题
- 场景化表达：具体场景，真实感受
- 数据支撑：用数据强化痛点严重性

**示例**：
```
[痛点场景图] + [痛点描述] + [用户真实感受]
```

#### 3. 产品解决方案（展示价值）

**目标**：展示产品如何解决用户痛点

**设计要求**：
- ✅ 对比展示：问题 vs 解决方案
- ✅ 逻辑清晰：问题 → 原因 → 解决方案
- ✅ 视觉化：用图示说明，不冗长
- ✅ 价值突出：强调产品带来的改变

**文案策略**：
- 问题描述：重述用户痛点
- 产品方案：介绍产品解决方案
- 价值说明：强调产品带来的改变

**示例**：
```
[问题场景] + [产品解决方案] + [价值改变]
```

#### 4. 核心卖点（突出优势）

**目标**：突出产品核心优势，差异化竞争

**设计要求**：
- ✅ 展示 `Global_Core_Sell` 和 `Global_Assist_Sell`
- ✅ 一卖点一版块，清晰分层
- ✅ 使用对比、数据、示意图
- ✅ 文案简洁，逻辑清晰

**卖点展示策略**：

**核心卖点（Global_Core_Sell）**：
- 重点突出，最大篇幅
- 使用对比图、数据图
- 强调独特性、不可替代性

**辅助卖点（Global_Assist_Sell）**：
- 分3个版块展示
- 每个卖点配图说明
- 突出实用价值

**示例**：
```
[核心卖点] + [对比图/数据图] + [详细说明]
[辅助卖点1] + [示意图] + [说明]
[辅助卖点2] + [示意图] + [说明]
[辅助卖点3] + [示意图] + [说明]
```

- ✅ 场景多样，覆盖不同用户

## 视觉设计规范

### 色彩策略

#### 主色调选择原则
- 品牌一致性：使用品牌主色调
- 产品属性：美妆用柔粉色，数码用科技蓝
- 目标人群：女性用柔和色调，男性用冷色调

#### 辅助色搭配
- 对比色：用于强调关键信息
- 近似色：用于营造和谐氛围
- 中性色：用于背景、文字

### 字体策略

#### 字体选择
- 标题：使用粗体，醒目突出
- 正文：使用常规字体，清晰易读
- 说明文字：使用小字体，低调简洁

#### 字号规范
- 一级标题：36-48px
- 二级标题：24-32px
- 正文：16-20px
- 说明文字：12-14px

### 图片质量要求

#### 拍摄质量
- 分辨率：≥ 300dpi
- 光线：充足均匀，无过曝或暗角
- 构图：主体突出，背景简洁
- 色彩：真实还原，无过度美化

#### 处理规范
- 不使用过度滤镜
- 不使用过度磨皮
- 不使用过度合成
- 保持产品真实感
