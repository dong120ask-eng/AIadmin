## 工作流1：营销战略工作流

**触发条件**："做市场定位""品牌策略""定价方案""竞争对手分析""品牌从0到1"

**步骤流程**：

```
步骤1：市场定位分析 → 步骤2：用户洞察 → 步骤3：品牌策略 → 步骤4：定价策略
```

1. **市场定位分析**（调用模块1）：绘制竞争定位图谱→选择商战策略→撰写定位陈述
   - 输入：行业/品类/竞品信息
   - 输出：《市场定位分析报告》含竞争图谱+商战策略+定位陈述
2. **用户洞察**（调用模块2）：识别决策类型→绘制决策旅程→设计助推策略
   - 输入：目标人群描述
   - 输出：《用户洞察分析报告》含决策旅程+心理触点+助推策略
3. **品牌策略**（调用模块3）：蓝海价值曲线→超级符号设计→五感品牌体系
   - 输入：定位陈述+用户洞察
   - 输出：《品牌策略设计报告》含价值曲线+超级符号+五感体系
4. **定价策略**（调用模块7）：价格敏感度测试→策略选择→价格呈现优化
   - 输入：产品成本+竞品价格+用户感知
   - 输出：《定价策略方案》含价格测试+策略选择+呈现优化

**组合打法**：先软后硬——小红书意外发现+B站测评建立信任（1-4周）→抖音痛点解决+直播带货转化（8-12周）

## 工作流2：爆款内容生产工作流

**触发条件**："帮我做爆款视频""分析我的账号做内容""帮我生成小红书图文""生产爆款内容""帮我写种草脚本"

**5阶段流水线**：

```
阶段1：账号诊断与画像 → 阶段2：内容策略决策 → 阶段3：脚本创作引擎 → 阶段4：视听素材规划 → 阶段5：成片输出
```

### 阶段1：账号诊断与画像

- **输入**：平台名称 + 账号ID或主页链接 + 产品信息（可选）
- **分析5维度**：粉丝画像（年龄/性别/地域/消费力）、内容标签（主标签+辅标签）、互动数据（均播/赞粉比/评赞比/收藏率）、内容风格（专业型/亲和型/潮流型/故事型）、竞品对标（同赛道Top5+差异化机会点）
- **输出**：账号画像卡（含人群画像+标签矩阵+数据基线+内容机会点）
- **模板**：见 [references/viral-content-production-workflow.md](references/viral-content-production-workflow.md) 账号画像卡模板

### 阶段2：内容策略决策矩阵

5个关键决策点，逐步确定内容方向：

1. **商业目标→种草类型**：即时转化选硬性种草 / 品牌建设选软性种草 / 两者兼顾先软后硬
2. **内容形式→输出平台**：短视频(抖音/快手/视频号) / 图文(小红书) / 文章(头条/百家号) / 多平台适配
3. **内容类型→创作方向**：知识科普 / 测评对比 / 使用教程 / 生活vlog / 情绪故事 / 好物分享
4. **发布方式→渠道选择**：自营号发布 / 达人合作 / 混合策略
5. **转化路径→行动设计**：挂车带货 / 直播间引导 / 搜索引导 / 私域沉淀

- **决策树与判定标准**：见 [references/viral-content-production-workflow.md](references/viral-content-production-workflow.md) 阶段2完整决策矩阵

### 阶段3：脚本创作引擎

4步脚本生产流程：

1. **钩子选择**：从40+钩子库匹配3秒开场 — 见 [references/hook-library.md](references/hook-library.md)
2. **框架匹配**：根据策略自动匹配对应种草框架（硬性12种+软性22种） — 见种草双引擎部分
3. **脚本撰写**：按选定框架逐段生成，每段含口播文案+画面描述+字幕标注+转场指示
4. **互动设计**：评论引导 / 行动号召 / 话题标签

- **脚本模板**：见 [references/viral-content-production-workflow.md](references/viral-content-production-workflow.md) 脚本输出模板

### 阶段4：视听素材规划

按5个维度规划全部视听素材：

- **视频素材**：类型(实拍/素材库混剪/动画/AI生成/图文轮播) + 时长(15s/30s/45s/60s/3-5min/10-25min) + 画幅(9:16竖屏/16:9横屏/3:4小红书)
- **配音方案**：音色(专业/亲和/活力/磁性/少女/大叔) + 语速(快/中/慢) + 情绪(激情/温暖/冷静/幽默)
- **BGM方案**：风格匹配内容节奏 + 人声音量比(3:1~5:1) + 版权合规
- **字幕方案**：样式(基础/花字/手写体/弹跳) + 关键词高亮(每段2-3个) + 特效
- **转场方案**：类型(硬切/叠化/推拉/缩放/创意) + 节奏配合BGM节拍

- **详细规格对照表**：见 [references/viral-content-production-workflow.md](references/viral-content-production-workflow.md) 阶段4完整素材规划

### 阶段5：成片输出

根据内容形式输出完整方案：

- **短视频**：生成分镜图片→配音文本标注→字幕时间轴→转场编排→合成指导（含完整时间轴编排）
- **小红书图文**：封面图(1张)+内页图(3-9张)+笔记文案+话题标签，按软性种草5种框架适配
- **文章**：SEO标题(3个备选)+结构化正文+配图描述+关键词布局(密度2%-5%)
- **多平台适配**：核心素材一次生成，按平台规则微调（标题/开头/节奏/结尾/图片/标签）

- **输出模板**：见 [references/viral-content-production-workflow.md](references/viral-content-production-workflow.md) 短视频/小红书图文/文章输出模板

### 使用示例

- **示例1（抖音种草短视频）**："帮我分析抖音号@护肤小达人，做一个美白精华的种草视频"
  → 阶段1画像卡（25-35女性/成分党/亲和型）→ 阶段2决策（硬性种草+短视频60s+痛点解决型+自营号+挂车带货）→ 阶段3脚本+分镜 → 阶段4视听素材 → 阶段5成片方案

- **示例2（小红书图文笔记）**："分析我的小红书账号，做一组香薰蜡烛的图文笔记"
  → 阶段1画像卡（22-30女性/家居美学/亲和型）→ 阶段2决策（软性种草+图文6张+氛围感大片型+自营号+搜索引导）→ 阶段3图文脚本 → 阶段4封面内页 → 阶段5封面+内页图描述+文案

- **示例3（多平台内容矩阵）**："帮我的护肤品做全平台内容"
  → 阶段1画像卡 → 阶段2决策（先软后硬+多平台）→ 阶段3按平台生成不同框架脚本 → 阶段4按平台规划素材 → 阶段5短视频+图文+文章+一源多发适配方案

## 工作流3：爆款复刻工作流

**触发条件**："拆解这个视频""分析这个产品""帮我复刻爆款""生成内容工作流"

**步骤流程**：

```
步骤1：输入识别 → 步骤2：深度分析 → 步骤3：工作流配置 → 步骤4：批量内容生成
```

1. **输入识别**（调用模块9）：识别输入类型（视频链接/产品截图/产品信息），确定分析路径
2. **深度分析**（调用模块9）：视频拆解6维度（钩子/结构/节奏/视觉/话术/数据）+ 产品逆向5维度（卖点/人群/场景/竞品/定价）

   - 输出：工作流配置JSON + 创作指南
4. **批量内容生成**（调用模块5种草双引擎）：按硬性12种+软性22种框架批量产出内容

## 工作流4：种草内容矩阵工作流

**触发条件**："写种草文案""做全平台种草""硬性种草""软性种草""种草双引擎"

**步骤流程**：

```
步骤1：种草类型决策 → 步骤2：框架选型 → 步骤3：核心素材库构建 → 步骤4：批量内容生产 → 步骤5：跨平台适配
```

1. **种草类型决策**：即时转化选硬性种草（效果1-7天）/ 品牌建设选软性种草（效果1-12月）/ 组合使用先软后硬

2. **框架选型**：
   - **硬性种草12种**：抖音6种（痛点解决/场景代入/对比测评/教程干货/情绪共鸣/权威背书）+ 小红书6种（好物分享/使用教程/避坑指南/成分党/生活记录/专业测评）
   - **软性种草22种**：短视频5种 + 小红书5种 + 文章6种 + B站6种

3. **核心素材库构建**：卖点3-5个 + 参数 + 场景描述 + 痛点 + 真实经历 + 优缺点 + 人群画像 + Q&A

4. **批量内容生产**：按选定框架逐个产出，每个框架独立成稿

5. **跨平台适配**：按平台特性调整（抖音快节奏强情绪/小红书精致有氛围/头条专业有深度/B站有趣有干货）

**推荐节奏**：蓄水期1-4周（软性种草建立信任）→ 加速期4-8周（软性扩大覆盖）→ 收割期8-12周（硬性驱动转化）

**指导**：见 [references/seeding-copywriting-framework.md](references/seeding-copywriting-framework.md)、[references/soft-seeding-framework.md](references/soft-seeding-framework.md)

**触发条件**："搭私域""直播带货""电商运营""活动策划""大促方案""社群运营"

2. **直播带货**（调用模块11）：

   - 输出：《直播带货方案》/《主播话术手册》含排品表+话术脚本+投流计划

   - 输出：《电商运营方案》含诊断报告+优化策略+执行SOP

4. **活动策划**（调用模块13）：
   - 5W2H框架策划 → 活动类型选择（节日/品牌事件/跨界/促销/裂变）→ 执行Checklist → 数据复盘
   - 输出：《营销活动策划方案》含5W2H+执行Checklist+复盘模板

## 理论参考：16大核心能力模块

以下16个模块被6大工作流调用，提供理论支撑和执行方法论。

### 模块1：市场定位分析（→工作流1步骤1）

**理论来源**：《定位》《商战》《22条商规》《营销管理》
**核心能力**：STP分析、定位三策略（抢先/关联/重新定位）、商战四式（防御/进攻/侧翼/游击）、竞争定位图谱、定位陈述撰写
**执行方法**：先绘制竞争定位图谱（价格-品质/功能-情感二维矩阵）识别空白区，再选择商战策略（防御/进攻/侧翼/游击），最后撰写定位陈述
**关键要点**：定位不是说出你是什么，而是在用户心智中占据一个独特位置；避免"什么都想做"的定位模糊；定位陈述格式="对于[目标人群]，[品牌名]是[品类]中能够[差异化利益点]的品牌"

### 模块16：GEO提示词架构优化（→工作流6+模块14协同）

本模块提供专业的GEO提示词架构设计能力，帮助商家构建与真实业务匹配的AI监控提示词系统。

**核心能力**：
- **主题优先提示词架构**：主题地图（问题空间/类别/用例/竞品群组）+ 非品牌发现（衡量进入新答案空间能力）+ 竞品对比（衡量竞争可见性）+ 品牌防御（衡量叙事控制和决策阶段）

**默认包配置**：
- 5个主题
- 50个提示词（每主题10个）
- 30-32个非品牌发现

- 5-8个品牌防御

{

      "topic": "主题名称",

## 种草双引擎：硬性种草与软性种草

### 种草双引擎定位

| 维度 | 硬性种草 | 软性种草 |
|------|---------|---------|
| 核心目标 | 即时转化，驱动下单 | 建立信任，驱动主动搜索 |
| 用户状态 | 被动接受→冲动购买 | 主动发现→自主决策 |
| 内容比例 | 50%产品信息+50%痛点/场景 | 70%价值内容+30%产品露出 |
| 典型结尾 | "点击左下角""现在下单" | 不引导购买，让用户自己决定 |
| 适合场景 | 促销活动、直播带货、新品首发 | 品牌建设、口碑积累、长期信任 |
| 效果周期 | 短期（1-7天） | 中长期（1-12个月） |
| 搭配策略 | 硬性种草冲量+软性种草蓄水 | 先软性种草蓄水→硬性种草转化 |

### 硬性种草心法与执行要点

种草的本质：**有情绪地用嘴讲给朋友听，你为什么喜欢它！**

4个核心心法及执行要点：
- **为什么喜欢它（真实感受）**：不要堆砌广告词，投入产品真实使用后表达感受。"这个梳子超牛！不管你怎么搓，一点都不会打结"而非"柔力圆润齿头，弹力优质气囊"
- **有情绪（拒绝平淡）**：该惊叹要惊叹，该吐槽要吐槽。文案的死穴是平淡，你自己都激动不起来，别人怎么会激动下单
- **用嘴讲（聊天口吻）**：把文章当聊天记录写，句子要短，语气词要多，读起来要顺嘴。禁止"综上所述""既然那么"
- **给朋友听（分享而非推销）**：一对一分享感，"我有好东西，咱俩一起爽"，而非"我有货，快给我钱"

**硬性种草12大框架**：

**抖音6种**——痛点解决型（功能产品：痛点开场→放大→产品引入→效果对比→行动指令）、场景代入型（家居食品：搭建场景→产品融入→品质展示→代入强化）、对比测评型（美妆数码：痛点→对比→验证→强化优势）、教程干货型（复杂产品：痛点→分步讲解→效果→要点回顾）、情绪共鸣型（礼品情感：情绪触发→故事→价值传递→情感驱动）、权威背书型（高客单价：背书引入→卖点展示→认证支撑→购买引导）

**小红书6种**——好物分享型（通用爆款：场景痛点切入→产品+真实细节→总结推荐）、使用教程型（高收藏率：痛点→分步方案→产品配合→效果对比）、避坑指南型（话题性强：踩坑→原因→替代→产品推荐）、成分党型（美妆保健：成分→原理→产品→使用建议）、生活记录型（最受欢迎：场景→产品融入→真实反馈→生活化结尾）、专业测评型（数码家电：测评背景→实测→数据对比→结论建议）

**完整案例与万能模板**：见 [references/seeding-copywriting-framework.md](references/seeding-copywriting-framework.md)

### 软性种草心法与执行要点

种草的"三无原则"及执行要点：
- **无推销感**：禁止"强烈推荐""必买""不买后悔""库存告急""限时优惠"。替代话术："我一直在用""用了一段时间后发现""已经推荐给朋友了"
- **无违和感**：产品出现在它本该出现的地方，厨房视频里展示厨具是自然的，而非为了展示而刻意安排。检验标准：去掉产品信息后，场景本身是否合理
- **无压迫感**：给用户选择权，"要不要买是你的事，我只是告诉你有这个东西"。禁止"你一定要用这个""每个女生都必须有"

用户防御3层绕过策略：
- **识别防御**（"这是广告"）→ 让产品出现场景足够自然，用户先被内容吸引再注意到产品
- **动机防御**（"为什么推荐"）→ 展示真实使用经历，"用了一年多了"比"真的很好用"更有说服力
- **说服防御**（"说的是真的吗"）→ 提供客观可验证信息，展示真实使用场景和前后对比

**软性种草22大框架**：

**短视频5种**——生活vlog自然露出型、干货分享+工具推荐型、情绪故事+产品解决型、好物使用体验型、对比评测型

**小红书5种**——意外发现型、踩坑避坑型、成分/技术党型、氛围感大片型、使用日记型

**文章6种**——知识科普+产品示例型、行业分析+品牌提及型、个人经历+产品陪伴型、问题解决方案型、观点输出+案例支撑型、SEO优化型

**B站6种**——测评视频型、开箱体验型、使用教程型、行业深度解析型、UP主日常型、横向对比型

**完整脚本模板与8个实战案例**：见 [references/soft-seeding-framework.md](references/soft-seeding-framework.md)

### 跨平台改写策略

改写前先建立核心素材库（卖点3-5个/参数/场景描述/痛点/真实经历/优缺点/人群画像/Q&A），再根据平台特性调整：

| 维度 | 抖音/快手 | 小红书 | 头条/百家号 | B站 |
|------|---------|--------|-----------|-----|
| 时长 | 15-60秒 | 无限制 | 1000-3000字 | 5-25分钟 |
| 风格 | 快节奏强情绪 | 精致有氛围 | 专业有深度 | 有趣有干货 |
| 开头 | 3秒法则抓眼球 | 标题党+目标人群 | 悬念引入 | 价值预告 |
| 核心 | 痛点+解决 | 发现+分享 | 知识+分析 | 教程+测评 |
| 结尾 | 不引导购买 | 轻引导 | 总结建议 | 三连引导 |
| 互动 | 评论回复 | 收藏引导 | 评论互动 | 弹幕引导 |
| 防御心理 | 最强，遇广告本能划走 | 对硬广识别力强但接受软性 | 需建立信任再推荐 | 反感一切硬广 |

- 直播带货核心：选品比话术重要，5段式排品决定80%的转化效果
