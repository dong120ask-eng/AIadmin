# 逍遥模拟器多开适配
scripts/memu.py支持list/status/apps及创建、克隆、后台启动、单实例停止、安装APK；变更默认plan，apply后执行。参考 [官方命令依据](references/memu.md)。
先软件技能核对本机官方MEmu与memuc.exe，运行实际help/listvms后登记实例索引与名称。不假定端口按固定步长，不随机连接IP；记录当前实例实际ADB序列号/本机映射端口，经getprop对应核验后注册。
一实例一账号，clone仅用于环境准备；不得把克隆出的登录态当成第二个合法独立账号，后续由用户分别登录并核对身份。
不同模拟器实例用各自device_id，独立队列；同实例串行。素材先存电脑，再走共享文件/ADB传入并在目标App核对可见性。
软件未安装、虚拟化配置未满足或需重启时记录人工步骤，不关闭安全软件、修改设备指纹、强制改系统保护或替用户重启。本轮只开发适配文件，模拟器实跑留下一阶段。
