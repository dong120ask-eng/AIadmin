# 定位理论指南

## 概览

定位理论是现代营销学的核心理论体系，由里斯和特劳特创立。本指南整合了《定位》《商战》《22条商规》三部经典著作的精华，为品牌定位提供系统化的方法论。

---

## 一、定位理论核心

### 1.1 核心洞察

**商业竞争的终极战场不是市场，而是潜在顾客的心智**

**定位的本质**："与众不同"，而非"做得更好"

### 1.2 定位的三个关键要素

| 要素 | 定义 | 评估标准 |
|-----|------|---------|
| **独特性** | 与竞争对手有明确区分 | 是否能在消费者心智中占据一个独特位置 |
| **利益性** | 能为用户带来实际价值 | 是否解决了用户的真实痛点 |
| **可信性** | 能让用户相信 | 是否有足够的信任状支撑 |

### 1.3 定位的三种基本策略

#### 策略1：领导者定位

**适用条件**：市场第一名或开创新品类

**核心方法**：
- 占据品类第一的位置
- 强化"品类领导者"认知
- 抢占行业关键词

**定位陈述模板**：
> [品牌名]是[品类]的领导者，因为我们[核心优势]，所以[用户利益]

**案例**：
> 可口可乐是可乐品类的领导者，因为我们拥有百年配方，所以带来经典独特的口味体验

#### 策略2：跟随者定位

**适用条件**：市场第二名或第三名

**核心方法**：
- 寻找领导者的弱点
- 找到差异化空位
- 强调与领导者的区别

**定位陈述模板**：
> [品牌名]是[品类]中[差异化定位]的品牌，因为我们[差异化优势]，所以[用户利益]

**案例**：
> 百事可乐是更年轻、更时尚的可乐，因为我们追求创新与激情，所以带来更清爽的口感体验

#### 策略3：重新定位

**适用条件**：改变消费者认知或攻击竞争对手

**核心方法**：
- 改变消费者对品类的认知
- 攻击竞争对手的弱点
- 创造新的认知框架

**定位陈述模板**：
> 传统的[品类]存在[问题]，[品牌名]通过[创新方式]，解决了这个问题，带来[用户利益]

**案例**：
> 传统的香烟有害健康，万宝路通过西部牛仔的形象，重新定义了香烟的自由与冒险精神

## 二、商战四式

### 2.1 四种战略形式

根据竞争地位选择不同的战略形式：

| 战略形式 | 市场地位 | 核心原则 | 典型案例 |
|---------|---------|---------|---------|
| **防御战** | 市场领导者 | 封堵竞争对手的最强攻击点 | 可口可乐 vs 百事可乐 |
| **进攻战** | 第二三名 | 集中兵力攻击对手的弱点 | 百事可乐挑战可口可乐 |
| **侧翼战** | 小企业/新品牌 | 速度和创新，抢占无人竞争区域 | 特斯拉进入电动车市场 |
| **游击战** | 微小企业 | 小规模进攻，快速撤退 | 本地小品牌 |

### 2.2 防御战（市场领导者专用）

**核心原则**：
1. 只有市场领导者才能打防御战
2. 最好的防御是自我进攻（主动升级）
3. 要封堵竞争对手的每一次进攻

**行动要点**：
- 持续强化品牌在消费者心智中的位置
- 快速推出新品或升级，不给竞争对手机会
- 抢占所有相关品类和关键词

**风险提示**：
- 领导者自大，忽视挑战者
- 放弃细分市场，给竞争者机会

### 2.3 进攻战（第二三名挑战第一名）

**核心原则**：
1. 找到领导者的弱点
2. 集中兵力攻击弱点
3. 在狭窄的战场建立优势

**行动要点**：
- 研究领导者，发现其未被满足的市场需求
- 集中所有资源攻击这个弱点
- 避免在领导者优势领域正面交锋

**案例分析**：
- 百事可乐：攻击可口可乐"老派"，定位为"年轻一代的选择"
- 红牛：攻击传统饮料的"平淡"，定位为"能量饮料"

### 2.4 侧翼战（寻找无人竞争的蓝海区域）

**核心原则**：
1. 寻找无人竞争的市场空白
2. 出其不意，速度要快
3. 追击要坚决，迅速扩大战果

**行动要点**：
- 找到被领导者忽视的细分市场
- 快速推出产品，抢占心智位置
- 扩大战果，防止领导者跟进

**案例**：
- 特斯拉：在传统汽车巨头忽视的电动车领域切入
- 苹果：在智能手机蓝海中用iPhone重新定义市场

### 2.5 游击战（小企业生存之道）

**核心原则**：
1. 找到一块小到足以守得住的市场
2. 无论多么成功，都不要表现得像领导者
3. 准备好随时撤退

**行动要点**：
- 选择细分市场，聚焦一个垂直领域
- 保持小而灵活，避免正面竞争
- 快速响应市场变化，调整策略

**案例**：
- 本地特色小店
- 垂直领域的专业工具品牌

## 三、22条商规精华

### 3.1 核心商规

| 商规 | 内容 | 营销启示 |
|-----|------|---------|
| **领先定律** | 首先进入市场比后来做得更好更重要 | 抢占心智第一位置 |
| **品类定律** | 若不能成为品类第一，就创造一个新品类 | 创新品类成为第一 |
| **心智定律** | 市场的终极战场是消费者的心智 | 关注消费者认知而非产品 |
| **认知定律** | 营销是认知之战，而非产品之战 | 改变消费者认知 |
| **聚焦定律** | 强有力的品牌必须代表一个品类 | 保持品牌聚焦 |
| **阶梯定律** | 消费者心智中有品牌阶梯 | 争取第一位置 |
| **二元定律** | 市场最终会演变为两个品牌竞争 | 成为第一或第二 |
| **对立定律** | 与领导者相反定位 | 寻找差异化对立面 |
| **牺牲定律** | 有所舍才能有所得 | 聚焦核心优势 |
| **延伸定律** | 品牌延伸会削弱品牌力 | 谨慎品牌延伸 |
| **属性定律** | 每个品牌都有一个专属属性 | 抢占核心属性 |
| **坦诚定律** | 承认负面反而赢得信任 | 诚实营销 |
| **单一定律** | 在某一领域做到极致 | 保持专注 |
| **莫忘定律** | 不要忘记成功的原因 | 坚持核心定位 |

### 3.2 商规应用矩阵

**判断品牌定位是否有效的快速检查表**：

- [ ] 是否是某个品类的第一或第二
- [ ] 是否占领了消费者心智中的独特位置
- [ ] 是否有明确的差异化利益
- [ ] 是否有足够的信任状支撑
- [ ] 是否避免过度品牌延伸
- [ ] 是否聚焦于核心优势
- [ ] 是否承认并解决了负面问题
- [ ] 是否保持了品牌的一致性

## 四、STP定位分析框架

### 4.1 STP三步法

#### Step 1：市场细分（Segmentation）

**细分维度**：
- **地理细分**：地区、城市等级、气候
- **人口统计**：年龄、性别、收入、职业、教育
- **心理特征**：价值观、生活方式、个性
- **行为特征**：使用频率、品牌忠诚度、购买动机

**细分方法**：
1. 选择细分维度
2. 收集市场数据
3. 识别细分市场
4. 评估细分市场的吸引力

**评估标准**：
- 市场规模
- 增长潜力
- 竞争强度
- 可进入性
- 与企业资源的匹配度

#### Step 2：目标市场选择（Targeting）

**目标市场选择策略**：

| 策略 | 描述 | 适用条件 |
|-----|------|---------|
| **无差异营销** | 忽略细分市场差异 | 标准化产品，市场同质化高 |
| **差异化营销** | 为多个细分市场提供不同产品 | 市场规模大，消费者需求差异大 |
| **集中化营销** | 聚焦一个或少数几个细分市场 | 资源有限，细分市场有吸引力 |

**目标市场评估**：
- 细分市场的规模和增长潜力
- 细分市场的结构性吸引力
- 企业的目标和资源

#### Step 3：品牌定位（Positioning）

**定位方法**：
1. **属性定位**：基于产品或服务特性
2. **利益定位**：基于为用户带来的利益
3. **用户定位**：基于目标用户群体
4. **竞争定位**：相对于竞争对手的位置
5. **质量/价格定位**：基于性价比
6. **用途定位**：基于使用场景

### 4.2 定位陈述模板

**标准模板**：
> [品牌名]是[品类]中[差异化定位]的品牌，因为我们[核心优势/信任状]，所以[用户利益]

**示例**：

**示例1（领导者定位）**：
> 茅台是中国白酒行业的领导者，因为我们拥有百年工艺和稀缺的产地资源，所以带来无可替代的品质体验

**示例2（跟随者定位）**：
> 小米是性价比高的智能手机品牌，因为我们采用互联网直销模式，所以让更多人享受科技带来的美好生活

**示例3（侧翼战定位）**：
> OATLY是燕麦奶品类的开创者，因为我们专注植物基饮品研发，所以为乳糖不耐受人群提供健康选择

## 五、定位实战流程

### 5.1 市场定位分析流程

```
Step 1：市场分析
├── 市场规模评估（容量与增速）
├── 竞争格局绘制（竞品定位图谱）
├── 竞争强度判断（进入壁垒、可替代性）
└── 趋势机会识别（技术、政策、消费变化）

Step 2：定位机会挖掘
├── 品类空白点扫描
├── 差异化维度分析（产品、服务、价格、渠道、品牌）
└── 用户痛点优先级排序

Step 3：定位策略制定
├── 定位类型选择（领导者/跟随者/重新定位）
├── 定位陈述撰写（品牌名+品类+差异化利益+信任状）
└── 定位测试验证（内部逻辑自洽性检查）

Step 4：商战战略匹配
├── 竞争地位识别（领导者/挑战者/追随者/补缺者）
├── 战略形式选择（防御战/进攻战/侧翼战/游击战）
└── 战略行动规划（资源配置、战术配合）
```

### 5.2 竞品定位图谱绘制方法

**二维矩阵图法**：

选择两个关键维度（如：价格 vs 品质，高端 vs 亲民），将竞品位置标出，找到空白区域。

**示例**：

```
高品质
↑
|
竞品A |
|
←———————+———————→ 低价格
|
|
竞品B |
```

**三维度雷达图法**：

选择3-5个关键维度（品质、价格、服务、创新、品牌），绘制雷达图对比。

## 六、定位验证与优化

### 6.1 定位有效性检查清单

**自我检查**：
- [ ] 定位是否独特？
- [ ] 定位是否可信？
- [ ] 定位是否有市场？
- [ ] 定位是否可执行？
- [ ] 定位是否可持续？

**市场测试**：
- 消费者调研
- A/B测试
- 焦点小组讨论
- 竞品反应观察

### 6.2 定位调整原则

**何时需要调整定位**：
- 市场环境发生重大变化
- 消费者需求发生改变
- 竞争格局发生颠覆性变化
- 定位效果持续不佳

**调整注意事项**：
- 保持核心定位的一致性
- 渐进式调整，避免剧烈变化
- 充分沟通，解释调整原因
- 监测市场反应，及时优化

## 七、常见误区与避坑指南

### 7.1 定位常见误区

| 误区 | 表现 | 正确做法 |
|-----|------|---------|
| **以自我为中心** | 过度强调产品功能而非用户利益 | 从用户角度出发，强调用户利益 |
| **追求全能** | 想要满足所有用户需求 | 聚焦核心优势，放弃次要需求 |
| **盲目跟随** | 完全模仿领导者定位 | 寻找差异化空位，形成独特定位 |
| **频繁变更** | 定位经常改变，缺乏一致性 | 坚持核心定位，保持长期一致性 |
| **过度延伸** | 品牌延伸到不相关领域 | 保持品牌聚焦，谨慎品牌延伸 |

### 7.2 避坑指南

**避免定位陷阱**：
1. 不要试图"更好"，要"不同"
2. 不要试图满足所有人，要聚焦核心用户
3. 不要只关注产品，要关注消费者心智
4. 不要忽视竞争对手，要持续监测竞争动态
5. 不要僵化定位，要根据市场变化灵活调整

## 八、案例参考

### 8.1 成功定位案例

**案例1：苹果"Think Different"**
- **定位策略**：重新定位，挑战IBM和微软
- **定位陈述**：苹果是创意人士的选择，因为我们鼓励打破常规，所以释放创造力
- **商战战略**：进攻战，攻击竞争对手的平庸

**案例2：星巴克"第三空间"**
- **定位策略**：侧翼战，创造新品类
- **定位陈述**：星巴克是家和办公室之外的第三空间，因为我们提供独特的咖啡体验，所以成为社交和文化中心
- **商战战略**：侧翼战，抢占空白市场

**案例3：小米"性价比"**
- **定位策略**：跟随者定位
- **定位陈述**：小米是高性价比的智能手机，因为我们要让每个人都能享受科技，所以提供价格亲民的高品质产品
- **商战战略**：游击战，从低端市场切入

### 8.2 失败定位案例

**案例：某品牌过度延伸**
- **问题**：从高端化妆品延伸到大众消费品
- **结果**：稀释品牌高端形象，导致原有用户流失
- **教训**：避免过度品牌延伸，保持品牌聚焦
