# 产品逆向方法论

## 概述

产品逆向是通过分析产品界面截图，还原产品设计逻辑，生成可复用的产品方案和开发指令。

---

## 逆向5维度模型

### 维度1：界面结构解析

#### 导航设计类型

| 导航类型 | 特征 | 适用场景 |
|---------|------|---------|
| 底部Tab导航 | 3-5个主入口 | 核心功能APP |
| 顶部导航栏 | 标题+操作按钮 | 内容展示页 |
| 抽屉导航 | 侧滑展开 | 功能较多APP |
| 宫格导航 | 9宫格/12宫格 | 工具类应用 |
| 底部列表 | 功能列表 | 设置/个人中心 |

#### 卡片布局类型

```
标准卡片结构：
┌─────────────────────────┐
│  图片/图标区域          │
├─────────────────────────┤
│  标题                   │
│  描述文字               │
├─────────────────────────┤
│  操作按钮/标签         │
└─────────────────────────┘
```

#### 列表结构类型

| 列表类型 | 特征 | 交互特点 |
|---------|------|---------|
| 单列列表 | 垂直滚动 | 适合详情展示 |
| 双列网格 | 左右排列 | 适合商品展示 |
| 瀑布流 | 不规则排列 | 适合内容流 |
| 横向滑动 | 水平滚动 | 适合推荐模块 |

#### 表单元素识别

```
表单组件清单：
├── 输入框（文本/数字/密码）
├── 选择器（单选/多选）
├── 开关
├── 滑块
├── 日期选择器
├── 图片上传
├── 文件上传
└── 验证码输入
```

### 维度3：用户路径还原

#### 核心路径梳理

**路径1：注册登录流程**
```
启动页 → 引导页 → 手机号登录/注册 → 授权 → 首页
```

**路径2：内容浏览流程**
```
首页 → 分类/搜索 → 列表页 → 详情页 → 互动(收藏/评论) → 分享
```

**路径3：交易流程**
```
商品详情 → 加入购物车/立即购买 → 确认订单 → 支付 → 支付成功 → 订单详情
```

#### 决策节点识别

```
决策节点类型：
├── 入口决策：进入哪个功能
├── 选择决策：选择哪个选项
├── 确认决策：是否完成操作
└── 退出决策：是否离开页面
```

#### 转化漏斗分析

```
用户漏斗模型：
                    ┌────────────┐
                    │   曝光量   │  100%
                    └─────┬──────┘
                          │ -30%
                          ▼
                    ┌────────────┐
                    │   点击量   │  70%
                    └─────┬──────┘
                          │ -20%

                    ┌────────────┐
                    │   使用量   │  50%
                    └─────┬──────┘
                          │ -40%
                          ▼
                    ┌────────────┐
```

### 维度4：卖点设计挖掘

#### 差异化定位框架

```
差异化定位 = 目标用户 + 核心场景 + 独特价值

示例：
产品：在线问诊APP
目标用户：工作繁忙的上班族
核心场景：生病时快速获取专业建议
独特价值：30秒接通三甲医院医生
```

#### 价值主张提炼

| 价值类型 | 描述 | 呈现方式 |
|---------|------|---------|
| 功能价值 | 能解决什么问题 | 核心功能突出 |
| 体验价值 | 使用感受如何 | 界面设计/交互 |
| 情感价值 | 带来什么感受 | 品牌调性/文案 |
| 社会价值 | 体现什么身份 | 社交背书/标签 |

#### 用户痛点对应

```
痛点 → 功能映射：
痛点1：不知道选什么药 → 功能：智能推荐
痛点2：担心医生不专业 → 功能：资质展示
痛点3：不想排队等待 → 功能：即时接通
痛点4：不知道如何用药 → 功能：用药指导
```

### 维度5：技术架构抽象

#### 可复用组件分类

| 组件类型 | 包含内容 | 复用价值 |
|---------|---------|---------|
| 基础组件 | 按钮/输入框/卡片 | 高 |
| 业务组件 | 商品卡片/用户卡片 | 高 |
| 布局组件 | 列表/网格/瀑布流 | 高 |
| 动画组件 | 过渡/反馈/加载 | 中 |
| 业务模板 | 列表+详情组合 | 高 |

#### 交互模式归类

```
交互模式清单：
├── 下拉刷新
├── 上拉加载更多
├── 侧滑操作
├── 长按菜单
├── 拖拽排序
├── 多选模式
├── 空状态设计
├── 错误状态设计
└── Loading状态设计
```

#### 技术选型建议

```
前端技术选型：
├── 微信小程序：Taro/uni-app/原生
├── H5应用：Vue/React
├── APP：Flutter/React Native
└── PC后台：Vue/React+Element UI

后端技术选型：
├── 小型应用：Node.js/Express
├── 中型应用：Spring Boot/NestJS
└── 大型应用：微服务架构
```
