# 本地自媒体接续
项目目录使用用户指定路径或宿主当前工作目录，不假定电脑盘符。使用实际工具列表；不要把 Codex 工具名当作 Harness 工具。先运行 scripts/doctor.py 检查依赖，读取当前项目交接材料；云端包缺失时记录缺失，不重建假源码。

新完整套件入口为相邻 selfmedia-autopilot/SKILL.md；当前说明见自媒体技能套件/README.md，旧源码和接续材料保留于archive。不要继续依赖旧开发包的根目录路径。

## 路由
- 图文、稿件、视频：读取相邻 dsh-content-studio/SKILL.md。
- 手机连接、截图、传素材：读取相邻 dsh-android-control/SKILL.md。
- 设备实例、账号、队列：读取相邻 dsh-account-matrix/SKILL.md。
- 手机或浏览器草稿与发布核验：读取相邻 dsh-app-publishing/SKILL.md。

创建任务用 scripts/ops.py，命令和状态见 [台账操作](references/ledger.md)。台账只保存身份别名、素材路径、指纹和证据，不储存凭据。SQLite 设备锁用于本工具内协作，不能阻止其它软件控制手机。

先完成一条真实样稿，到草稿预览交回用户。最终发布确认绑定账号、标题、正文、素材、可见性、草稿证据；更改素材须新建任务。审批记录只能在得到本次明确人工确认后由执行器写入，不允许从“部署所有技能”推导发布授权。

内容、依赖安装、登录、草稿、正式发布分别报告状态。发布结果不明用 uncertain 保留设备锁，先核验作品列表；确认未发布才用 not-published 回到草稿重新确认。无法核实就保留阻塞，不能直接重试。

长任务在完成制作、草稿、提交与核验时保存检查点。用户消息作为当前任务的修改；安装、删除、提交、发布前遵守用户要求逐项确认。收到停止请求则不再执行界面输入，保留当前状态。
