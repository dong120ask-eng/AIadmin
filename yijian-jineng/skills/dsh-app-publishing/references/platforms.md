# 平台操作重点（按当前界面验收）
共用台账、内容质检与账号核验，平台操作以实际可见能力为准，不能从此表推导未经实测的接口支持。

| 平台 | 编辑与预览重点 | 成功核验 |
|---|---|---|
| 小红书 | 区分图文/视频；顺序、首图、标题、正文、话题、可见性；个人主页账号与目标实例一致 | 作品列表/详情中的对应内容与平台状态 |
| 抖音 | 视频/图文入口分别验证；封面、标题、话题、音乐授权、可见性 | 个人作品或创作者后台回执，区分审核与公开 |
| 今日头条 | 文章/微头条/视频各自编辑；标题、封面、正文格式 | 后台内容管理中的对应作品与状态 |
| 公众号 | 优先已配置的官方草稿接口或真实后台；排版、封面、摘要、作者、预览；普通微信聊天不是公众号编辑入口 | 公众号对应草稿/素材/发布管理记录 |
| 视频号 | 从已登录微信的实际视频号入口进入；视频号身份不等于微信昵称 | 视频号作品列表，核对账号和作品 |
| 快手 | 实际发布入口、视频、封面、标题和可见性；草稿须可恢复 | 当前账号作品及平台回执 |
| B站 | 投稿类型、分区、封面、标题、简介与版权声明 | 稿件管理中的稿件和审核状态 |
| 百家号 | 后台或实际 App 能力先核实，图文/视频分别验收 | 内容管理的对应作品与状态 |

尺寸、字数、时长以当前官方说明或后台校验为准，不在此表写容易过时的数字。账号权限不足、登录过期、平台验证或素材不可见时记录 blocked/人工处理，用户完成后再续。
记录发布结果时可用作品 ID 代替 URL，但需配真实作品证据。台账 published 表示提交后的对应作品已核验，不代表内容已经公开、推荐或通过全部平台审核；证据中明确实际状态。
