# 下一阶段由用户与助手开始测试
本轮范围为技能/脚本开发、静态检查、打包和目录整理。不在本轮调用生成模型、启动模拟器、登录账号或真实发布。

1. 环境：依赖、ffmpeg字体、浏览器、逍遥memuc路径及用户权限。
2. 市场策划：真实产品事实与来源，输出策略、人群、证据和禁用表述。
3. 爆款学习：每平台实际样本与指标，结构提取、未知项、原创框架迁移。
4. 混合账号：真实账号实例、分类/产品分配、独立内容、不同产物路径、失败恢复。
5. 电脑制作：卡片中文、音频、字幕、视频成片与QA；网络配音服务单独验证。
6. 逍遥：安装器签名、创建/克隆/启动、实例ADB身份、素材存储、不同账号登录与队列；不按端口公式猜测。
7. USB：两台已接通基础服务，后续验证App输入、真实身份、素材可见性、分身与锁。
8. 平台：13个平台逐项验证实际体裁、编辑、草稿、用户确认、唯一提交、作品ID、审核与公开状态。
9. 网页：当前CDP/Playwright接入、唯一页面/账号、文件上传、确认与DOM变更拦截。
10. 异常：未登录、素材缺失、不同账号、输入拒绝、提交超时与结果不明。不得盲目重发。

“文件开发完成”表示已有实现与操作技能，不表示账号/平台/模拟器已经实跑通过。动态元素定位在实际观察时选取，缺权限、字段或入口时转人工，不虚构支持。
未在本轮安装逍遥或补视频/浏览器依赖，安装技能与清单已交付。未知API模型、账号、实际设备配置由测试时填写。
