# 软件与设备准备
电脑：Python独立环境、Pillow、uiautomator2、PyYAML、ffmpeg/ffprobe；视频另需edge-tts/numpy（配音联网）；网页自动化另需Playwright与已授权浏览器。
逍遥：从https://www.xyaz.cn/或https://www.memuplay.com/官方入口下载，先核对签名、版本和SHA256，按实际安装器参数安装。没有核实winget的逍遥包ID，因此脚本不使用猜测ID。
本轮当前PATH未发现memuc.exe；也未在常用安装目录发现逍遥。安装、启动、驱动/虚拟化兼容性留后续测试。
手机：adb/scrcpy和uiautomator2已在此前部署，两个USB设备截图与XML读取成功；本轮不再连接或改变手机。
目标平台App由手机应用商店/官方渠道安装，具体APK根据机型/版本确认。多开优先逍遥独立实例或手机原生分身；不安装来源不明的多开容器，不伪装设备。
uiautomator2的设备侧JAR由已安装官方包初始化。需要日志、权限或UAC操作时由用户处理，不能关闭安全保护、替用户重启或绕过登录验证码。
