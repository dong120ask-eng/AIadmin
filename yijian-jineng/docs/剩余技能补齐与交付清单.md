# 剩余技能补齐与交付清单 — r5

按本对话已经明确的自媒体范围核对，旧版30技能缺少多项执行环节，并存在把开发阶段限制写进运营技能的问题。本轮新增17个技能、增强原有流程，现有47技能及17个平台入口；不是以目录数量证明平台已能发帖。

|需求/缺口|本轮实现|验证|
|---|---|---|
|产品与市场营销策划|保留完整营销资源及产品分析入口，接入事实资料与任务指纹|资源完整性及格式通过；真实产品策略需实际输入|
|各平台样本入库、来源追溯|content-source-library文本/HTML/RSS入库、去脚本、来源时间/指纹、重复来源记录|HTML入库、去重、XML实体拒绝通过|
|框架拆解与原创生成|viral-content-learning保留结构证据；remix.py仅选抽象结构与自己事实，不携带原文模仿|提示文件可直接交宿主或选定API，语义效果待实际内容测试|
|分类混合账号生成|原计划工厂、API预算客户端、原生助手accept接收器、原子成果保存|原子提交、重复提交、坏视频规格拒绝、旧计划保护通过|
|模型失败与调用成本失控|model-provider-runtime明确每日调用/令牌预留、429有限退避、未知连接不自动重试|预算阻止第二次网络调用、429退避及连接异常通过|
|电脑图文与文章排版|随包卡片渲染器、formatting.py安全HTML、正文和规格落盘|真实图片解码、HTML转义及主动链接拒绝通过|
|长中短视频与跨画幅素材|原配音字幕流水线，加video-format-adaptation明确片段/尺寸/帧率并保留音轨|实际合成视频转竖版180×320及音轨通过；在线配音本轮未调用|
|素材去重与版权来源|asset-library内容地址库及账号使用记录|跨账号使用需明确复用、来源/权利冲突不静默替换|
|内容质检缺实际闸门|content-quality-gate；台账拒绝普通/过期QA文件|事实未核验、健康声明缺失、证据变更不通过；任务和指纹必须一致|
|多账号日历与设备冲突|account-content-calendar带时区、账号间隔/日上限、设备串行|时区缺失拒绝、设备串行及跨日上限通过|
|USB手机/逍遥多开/网页|原设备工具与MEMUC；新校准、执行器精确绑定账号/设备/可见性|隔离后端流程通过；真实设备和App页面需后续校准|
|草稿执行只停在文字说明|publishing-calibration和publishing-workflow-runner，每步实时身份、唯一节点、截图及台账|错账号、未校准、误点发布按钮、可见性改变均停止|
|混合批次草稿|tools/batch_prepare.py全批预检、质检、claim、草稿、release串行|计划不连接后端，批次草稿完成后释放设备锁通过|
|提交后断线与重复发布|attempt在点击前持久登记，异常uncertain；publishing-recovery基于实际作品ID核验|提交异常只能点击一次、重复提交阻止、精确结果核验通过|
|交接手机与其他执行宿主|content-package-export只打包已审核正文/媒体/指纹|未质检不导出；包内不含审批、登录状态或SQLite|
|豆包/千问/WorkBuddy/Harness/Codex|assistant-deployment-bridge部署正式执行宿主；普通聊天导出知识包及调用指令|文件部署与知识导出明确区分，不假定聊天客户端具有本机权限|
|发布后2h/24h/72h复盘|selfmedia-analytics导入真实平台CSV和源指纹|重复观察窗、NaN拒绝、零阅读返回空率|
|爆款框架效果比较|content-experiment-lab可重复分配与二项率区间|样本不足不宣布胜者，非法事件数拒绝，不把观察差异当因果|
|平台遗漏|补企鹅号、网易号、搜狐号、大鱼号，与原13平台共17入口|入口和开发合同齐备；17平台均未宣称真实发布验收通过|
|部署与开发限制残留|一键部署计数动态读取；移除永久“当前不生成”禁令；清单分脚本/共享执行器/指令流程|47技能官方格式验证通过；旧版非结构化QA需新建任务重审|

本轮51项回归通过，没有真实模型调用、账号登录或发帖。UI执行测试使用隔离后端验证行为；实际媒体转码使用本机FFmpeg完成。真实平台还需要对应账号权限、实际页面校准和最终发布确认。网易号入口本轮在线访问未成功，先核对当前可用入口后测试，不假装可用。

新增17技能：content-source-library、content-quality-gate、asset-library、account-content-calendar、model-provider-runtime、content-experiment-lab、selfmedia-analytics、publishing-calibration、publishing-workflow-runner、publishing-recovery、content-package-export、assistant-deployment-bridge、video-format-adaptation、publish-penguin、publish-netease、publish-sohu、publish-dayu。

技能清单 config/skill-manifest.json 已取消笼统的implemented标记，分别列出instruction-workflow、script-and-instructions、shared-platform-executor及实际脚本路径。共享执行器表示需要现场配置，不表示每个平台选择器已经校准。旧版云端交接ZIP未自动迁回的问题不以“重建了相似名字”冒充原包完整迁移，本轮交付以当前目录里的实际文件为准。
