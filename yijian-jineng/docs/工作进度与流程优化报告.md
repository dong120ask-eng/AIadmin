现有 47 个技能，17 个平台流程。上一版 r6 本地与 GitHub 52 项回归通过；本次新增进度台 6 项测试，合计 58 项本地通过。新版本云端测试结果应以实际运行记录为准。

## 本次实际优化

- 新增“查看工作进度”入口和离线中文页面，显示真实台账任务、当前环节、下一步、占用任务，支持搜索任务与平台。
- 查询以 SQLite 只读模式打开，不创建空台账；读取后关闭连接，避免 Windows 文件占用。
- 结果不明任务优先提示核验，保留锁，避免误把“失败”理解为可以重发。
- 台账损坏或结构不匹配时明确提示统计可能不完整，不以零任务宣称系统正常。
- 页面不导出账号 ID、设备序列号、正文或凭据；动态文本进行 HTML 转义，防止来源文本成为页面脚本。
- 输出限于工作目录内的专用目录，有其他文件则拒绝覆盖。
- 更新总控技能的用户流程：当前环节只收集必要输入，先展示一条样稿预览，再扩展账号矩阵。进度台不触发模型调用或发布。

本机检查时，主台账有 0 个已登记实例、0 个正式任务；这不代表手机没有安装 App 或没有账号，只表示它们尚未登记到这个运营台账。ADB、FFmpeg、scrcpy 在 PATH 可发现，MEMUC 未发现；未发现不等于未安装。两台手机此前完成基础连接记录，但本轮没有重测设备或执行发布。

## 还需补齐什么

| 优先级 | 缺口 | 建议交付或验收标准 |
|---|---|---|
| P0 | 一个真实平台运营闭环 | 一个账号：策划→电脑样稿→质检→真实草稿→确认提交→作品核验→数据复盘，逐步留证 |
| P0 | 平台与多开实例校准 | 按平台、体裁、设备、账号分别核验；确认媒体能被正确实例读取，不能复制原版配置到所有分身 |
| P0 | 模拟器验收 | 安装或定位真实 MEmu/MEMUC，测试实例列表、启动、ADB 连接、素材交接；不能只依靠命令适配文档 |
| P1 | 交互式配置向导 | 逐步填写产品、账号、设备、模型，验证必填项；示例与真实配置明确区分，密钥使用环境变量 |
| P1 | 页面变化检测技能 | 保存当前版本界面锚点；账号或关键控件变化时停止并要求重新校准，避免凭旧坐标点击 |
| P1 | 端到端异常演练 | 设备掉线、页面关闭、配额耗尽、验证码、重复运行、发布结果不明；验证能准确恢复且不重发 |
| P2 | 平台数据回收连接 | 有官方 API 或授权导出时自动入库，保留来源；不支持时继续 CSV 导入 |
| P2 | 定时运行与通知 | 明确主机开机条件、时区、设备空闲、跳过策略、结果通知；不要把内容日历当已部署调度器 |
| P2 | 内容质量评测 | 用真实样稿对比事实准确、原创表达、视觉质量和账号风格，低质量稿进入修改队列 |

其中现有技能已覆盖校准、恢复、安装与复盘，优先补真实配置和验收，无需另建同名技能增加数量。配置向导、页面变化检测、自动回收与定时运行仍是后续开发项，本次未冒称完成。旧云端全部对话与原始文件迁移也尚无完整下载证明，当前本地新套件不能替代该迁移验收。

## 推荐体验

让用户始终只看到三件事：现在做到哪一步、当前阻塞原因、下一步能做什么。正常流程保留自动衔接；产品资料缺失只询问当前必要信息。先交付电脑样稿预览，验证一个账号，再逐步增加平台和多开数量。发布前展示精确账号、素材和可见性；提交之后显示真实核验结果。遇到结果不明先查作品，不自动重复投稿。

双击套件内“查看工作进度.cmd”，或运行 tools/查看工作进度.ps1 -WorkspaceRoot "实际项目目录"。页面是离线快照，需重新运行刷新，不是后台监控服务。
