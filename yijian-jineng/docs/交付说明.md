# 自媒体全流程开发交付说明
交付版：2026-10-14。30个技能，覆盖本次指定范围。它们是当前开发实现与方法资源，真实账号、模型API、逍遥与平台发布测试按用户要求后续开始。

## 已交付能力
- 营销策划：product-market-marketing，保留用户原106文件知识包，改名并补当前宿主/资料事实约定。产品分析独立技能保留。
- 爆款学习、拆解与框架逻辑迁移：样本来源/指标记录、结构整理、原创新稿。
- 分类混合账号生成：按产品/分类/人设/平台分配，生成每账号独立任务和电脑产物。原生宿主与明确配置的API两条路径。
- 电脑制作保存：中文卡片、配音字幕视频、技术质检；成品先留电脑。
- 发布执行：13个平台专用步骤，共用USB/逍遥/网页控制器，身份核验、锁、精确审批、一次提交与结果恢复。
- 逍遥多开：官方MEMUC实例管理适配，不猜端口、不开随机换机或删实例。
- 电脑/手机软件安装：复用、项目依赖、官方软件/安装器计划与执行。
- 干净目录与交付：指纹清单、非删除归档、当前单一ZIP。

## 代码与验收
所有SKILL元数据、Python语法、JSON和直接资源链接静态检查通过，详见开发静态检查.json。
本轮没有进行真实生成、手机输入、账号登录、模拟器启动、草稿或发布测试。现有USB基础读取能力来自此前验证；不将其扩展宣称为30技能运营通过。
平台定位采用运行时观察XML/DOM后选择实际唯一元素；本版不含未经真机观察的固定选择器，实际版本校准属于测试阶段。
API模型和凭据、真实产品/账号/设备实例由使用者配置。示例仅说明结构，不可当生产账号或发布许可。

## 软件状态
基础Python、uiautomator2、Pillow、PyYAML、adb、scrcpy、ffmpeg已经在前阶段使用；本轮不新增软件实装。
逍遥未发现现有安装；已交付安装技能、官方入口和MEMUC控制脚本，安装/驱动/虚拟化兼容性留后续准备验收。
视频和浏览器依赖分组提供，按实际缺失用安装技能补齐，不盲目修改全局环境。

## 使用
解压当前总包，先看README.md与docs/四助手部署与调用.md。项目部署用tools/deploy.py，DeepSeek入口为tools/DeepSeek一键入口.ps1。
本机项目已把新套件复制到三个项目发现目录，旧差异文件先备份；客户端加载与运行仍是后续测试事项。
测试顺序见docs/后续测试与验收.md，先一个产品、一个账号、一条内容，再增加平台和多开。
