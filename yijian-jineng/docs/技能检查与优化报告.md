# 技能检查与优化报告 — 2026-10-14

部署事务以单个宿主为边界，三宿主间及本地副本复制没有跨目录整体回滚；磁盘满时可能已有部分宿主完成，应依据返回备份路径恢复。保留的历史同名技能文件不会自动删掉，避免破坏用户自定义文件；版本升级有废弃资源时应人工审查。

便携包适用 Windows 10/11 x64。ARM、macOS、Linux 要单独构建运行环境，不能复制本包的 Python 二进制。内置依赖可以离线部署；FFmpeg、scrcpy、逍遥和 AI 宿主仍需额外软件。手机 USB 授权、账号登录、验证码无法通过技能复制完成。便携环境验证通过也不能保证一台从未安装 VC 运行库的电脑完全兼容，遇到 DLL 缺失按微软官方运行库流程处理。

MD 指令并不代表某个客户端支持技能目录。只有拥有本地文件和执行工具的宿主能执行部署及设备控制，普通豆包/千问聊天可作为内容助手，需要接到执行宿主才有操作能力。

GitHub Release ZIP 的 SHA256 可以检测损坏或与指定版本不一致；同包清单不是独立签名，不能证明发行者身份。发布版本应由可信仓库发布，MD 里的下载命令不得编造未存在的仓库链接。

建议验收顺序：部署与重装 → 内容生成/图文/视频 → 指定 USB 设备和模拟器 → 每个平台草稿 → 一条私密测试作品 → 多账号串行任务 → 故障恢复与数据复盘。在真实发布验收之前，本套件保持「开发交付、待平台验收」。
