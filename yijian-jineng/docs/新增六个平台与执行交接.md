# 新增六个平台与执行交接

开发日期：2026-10-14。新增简书、美篇、豆瓣日记、YouTube、TikTok、X 六个发布技能，以及一个可执行 platform-content-adapter 技能。套件现有54技能、23个平台流程。

| 平台 | 本次实现体裁 | 必须核验的设置 |
|---|---|---|
| 简书 | article | 编辑器格式、图片顺序、原创、可见性 |
| 美篇 | article、image | 排版预览、图片顺序、权利、可见性 |
| 豆瓣 | article（日记） | 日记入口、原创、可见性；未实现小组、评分或评论批量操作 |
| YouTube | video | 频道、受众、版权、适用内容披露、可见性 |
| TikTok | video | 账号、音乐权利、适用内容披露、可见性 |
| X | text、image、video | 帖子类型、当前账号限制、权利、可见性；未实现自动串帖 |

体裁是本工具支持范围，不是平台全部能力清单。长度、图片数量、视频时长、区域权限等不写死，需核对当前账号页面；不能把旧网上限制作为当前规则。

## 执行顺序

1. 内容工厂登记该平台与体裁；不支持的组合在计划阶段报错。电脑先保存正文与媒体，再建立真实任务。
2. 为任务提供真实账号与设备的 publishing-profile/v1。先 observe：本机浏览器或Android观察身份、编辑器和当前设置；不用未经观察的固定定位。
3. 补充 content_format 以及 platform_review：task_id、fingerprint、reviewer、confirmed、evidence。confirmed 的字段名来自 platform-content-adapter/references/capabilities.json，每一项 true 对应真实检查；evidence 是工作目录内非空文件的路径与SHA256。
4. 运行 platform-content-adapter/scripts/adapter.py --root 工作目录 --task 任务ID --profile 配置路径 --output 交接单路径。验证真实任务指纹、账号、文件、体裁和步骤，写入交接单。交接单不是发布许可。
5. 质检与校准通过后 claim→prepare。预览图文排版、顺序、上传完成和可见性；用户确认精确草稿后 approve→begin→submit一次，核验真实作品状态。

共享执行器会再次校验平台设置和证据。没有真实视频或标题步骤时YouTube任务不能进入执行；网页媒体没有文件上传步骤时停止；任务或证据变化不能复用旧审核。观察可以先于设置审核，但执行不可以。

本次测试为隔离代码与状态检查，不是六个平台实际发布证明。各平台真实页面、账号登录、验证码、富文本编辑和上传处理仍需现场校准验收。新平台复用现有执行器，不冒称已经具备固定平台选择器或官方API发布接口。
