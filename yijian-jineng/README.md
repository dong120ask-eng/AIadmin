# 自媒体全流程技能套件 · 开发交付版
交付日期：2026-10-14。工作目录：D:\一键自动化技能。四个助手入口含 DeepSeek Harness、WorkBuddy、豆包、千问，另支持 Codex 的通用项目技能来源。

本版完成用户本轮指定范围的技能文件与执行脚本开发，共30个技能。真实模型生成、平台账号、逍遥多开和实际发布按用户要求留下一阶段测试；不能把静态检查或文件部署理解成运营验收。

## 全流程
产品市场营销策划（复用完整106文件资料包并改名）→各平台爆款学习→结构逻辑拆解与原创框架迁移→分类/产品/账号混合生成→电脑图文与配音字幕视频保存→QA与版本指纹→指定手机/模拟器/网页账号草稿→用户确认→唯一提交→作品结果核验→台账复盘。
先生成和保存电脑文件，再操控设备发布。账号切换、多开实例和媒体路径分别登记；同设备串行，结果未知不重复提交。

## 文件入口
- skills/：30个标准技能目录，包含完整资源和代码。
- config/：13个平台路由、模型配置样例、混合计划及样本结构。
- docs/：四助手指令、软件与设备、后续测试和静态检查。
- tools/：一键PC流水线、DeepSeek入口、部署、打包和检查。
- requirements-base/video/browser.txt：分组安装依赖。

操作入口：[四助手部署与调用](docs/四助手部署与调用.md)、[下一阶段验收](docs/后续测试与验收.md)、[软件和设备](docs/软件安装与设备.md)。
默认Python是项目 .venv-harness/Scripts/python.exe。USB基础控制在此前接通过；本轮不重测真机。逍遥未在本轮安装或启动，安装技能与官方命令适配已交付。

## 一键PC准备
tools/one_click.py --root 工作区 --campaign config/campaign.json 默认为计划，不产生模型调用。
API生成需真实provider、model、凭据环境变量，并显式apply；选定API端点后产品资料将用于该端点的生成。也可由宿主已有模型按任务prompt逐单生成文件，无需另开API。
apply生成、制作，enqueue建立prepared任务；QA与发布许可另行取得。tools/DeepSeek一键入口.ps1 为Harness原生模型总控入口，传入用户本次请求。
最终“一键生成发布”由总控衔接完整链路，止于必要的人类确认/账号登录检查点，未授权不直接发布。

## 支持范围
13个平台：小红书、抖音、头条、快手、B站、视频号、公众号、百家号、微博、知乎、CSDN、掘金、西瓜。
发布器是可用的通用元素控制器 + 平台业务步骤，定位按当前XML/DOM实时选择，不冒称已经校准各平台固定选择器。
所有平台登录、权限、体裁、媒体可见性、UI定位、审核和公开状态均需后续实际验收；缺入口就报告人工处理。

## 部署
tools/deploy.py --target 工作目录/.dsh/skills 默认只列计划；apply复制，backup保留差异旧文件。WorkBuddy用.codebuddy/skills，通用用.agents/skills。
普通豆包/千问聊天端只上传资料并调用可用能力；没有本机执行连接时不能安装、控制手机或发布。API入口和聊天端分开。
