# 普通话多题材短剧导演

本技能负责“出指令”，global-short-drama 负责“生产与分发”。两者用 JSON 文件交接，不依赖 Codex 专用工具、跨聊天消息或多代理机制，同一代理顺序加载两个技能即可。用户一句“用这两个技能制作话题 X，N 集，每集 M 分钟”即可启动。首次默认中文/普通话、中国市场；按用户配置保留海外平台目标，翻译不自动开启。

先读 [多题材框架](references/genre-guide.md)。按用户选择或话题确定一个主类型、最多两个辅助类型，把重生/系统/先婚后爱等放入桥段标签，将2D/3D/写实影像风格和画幅单独配置。18类框架是本技能的编辑归纳，不是平台热榜分类或爆款因果证明。不要把三个既有男频3D样本推广到所有题材；用户只给话题时自主选择适合的类型并说明原因，不默认隐藏富豪或无限战力。

支持用户触发后直接在对话框提供火山方舟 API Key。只确认收到，不回显、不写入本技能或导演指令。已有话题、集数、时长、模型 ID 和密钥时直接启动生产技能；缺少信息一次补问，不能在用户已说“开始生产”后再要求重复确认同一生产动作。密钥由生产技能的 --key-stdin 入口读取，环境变量仍为可选方式。聊天/工具记录可能保留输入，不能保证对话密钥完全不留痕。

## 案例学习

需要近期同题材研究、反例或可测假设时加载同级drama-market-research/SKILL.md。把market-brief.json的来源、观察、证据等级、限制与试验假设保存在导演指令的market_research字段；生产会将该字段传入写稿和审稿上下文。无真实数据不填预测点赞或爆款概率。

先读 [方法论与证据](references/methodology.md)，用户给的红果样本见 [案例台账](references/cases.json)，对应的 [三个样本机制分析](references/sample-patterns.md) 给出普通话3D男频方向的首批生产规则。访问用户链接，解析实际剧名和播放页，结合允许访问的片段/字幕/用户剧本做逐集分析；无法访问的视频不声称看过。点赞、热度、播放、收藏、评分是不同口径，记录抓取日期、集数、口径和实际数值。无法获得数据就写 null。

学习输出是抽象叙事机制与适用条件，不复制人物、具体台词或标志性情节。先记录样本观察（集号/时间码/行为），再提出推断，最后提出原创应用。仅有宣传简介时只分析 premise/关系张力，不推断整剧节奏、完播率、点赞成因或盈利。用普通作品/失效情节作为反例检查幸存者偏差；无法取得反例时注明限制。用户说“所有方法论”时持续维护可增量案例库，不能宣称覆盖整个平台。

## 话题转为生产指令

明确观众与观看场景、题材及情绪承诺；提出三个不同冲突方向，用户已授权自动策划时自主选择并说明理由。建立主角的外部目标、内在需求、局限认识、不愿付出的代价与行动策略；重要配角也有独立目标。整剧按集数规划，每集写出目标、阻力、策略、选择、后果、局部兑现与下集承接；每次反转有前因与后果，最后一集收束而非留空。伏笔建立引入集/证据/回收集的计划，避免只列“悬念”却没有答案。

使用方法论的评分表查开场是否可拍、因果是否闭合、人物是否主动、爽点是否有代价、语言是否普通话口语、镜头/对白能否在目标时间完成。零分项先重写，再交生产，不把主观评分称为预测爆款率。时长用秒，不用“多少字约等于多少分钟”替代配音与剪辑实测。

读取 [交接协议](references/handoff.md)，生成项目目录里的 director-brief.json，新项目使用schema_version=2及genre字段。从生产技能 assets/genre-frameworks.json 选择实际代码并读取主类型规则，按其episode_engine写逐集任务。从 assets/project.example.json 创建 project.json：复制话题、集数、时长、zh-CN 与目标平台，genre与导演一致或设auto采用导演选择；brief_path用绝对路径，保留quality.enabled=true；用户控制台模型ID不得擅自替代。API Key不写到两份技能或交接文件。

导演指令至少包含可执行的创作约束、全剧每集节拍、角色一致性要求、可视化呈现、普通话声音设计、原创边界、需要供片的素材与 QC 条件。不足以实现一致性时指示生产停在样片，不把需求文本当成已完成的技术能力。

## 联合启动

加载同级global-short-drama/SKILL.md（部署时两个技能应放在同一skill root；否则从宿主技能目录定位），执行drama.py plan校验交接与含审稿/返修的规模。确认已有授权/预算后执行run --episode 1；run先写稿、审稿，失败最多按配置返修，未通过不生成视频。在视频pending时允许用户插话；看完样片确认类型情绪和声画后再做其余集。模型打分仅为编辑辅助，不能据此保证高质量或爆款。跨平台部署方式见 [部署与验收](references/deployment.md)。

最终交付应显示实际完成阶段和平台回执。只生成导演 JSON 不能说“短剧制作完成”；中文样片完成不能说“全球市场适配完成”；上传待审不能说“已发布”。
