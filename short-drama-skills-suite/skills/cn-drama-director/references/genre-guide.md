# 多题材框架与任务逻辑

本技能自定义 18 个主类型，另有 general 通用后备框架，不声称它们是平台完整分类或已验证的爆款配方。可执行规则存放在生产技能 assets/genre-frameworks.json，导演和生产读取同一规则源。主类型只有一个，辅助类型最多两个；题材、桥段、人物视角、视觉形式分开，不把女性观众等同于爱情，也不把3D等同于男频。

| 类型代码 | 追看承诺与主线框架 | 单集任务示例（原创方向，不是固定剧情） |
|---|---|---|
| urban-rise | 能力得到承认；困境→小胜→资源反噬→代价选择→公平兑现 | 修好一台关键设备，却因此承担更难交付 |
| romance | 关系距离改变；差异→协作→信任→价值分歧→双向选择 | 两人合作处理一次失约，用行动暴露需求与回应 |
| family | 理解、责任与边界；家事分歧→受伤→看见彼此→行动修复 | 一次照护安排迫使家庭成员重新分担责任 |
| women-growth | 自主与能力重建；限制→试探→积累→失败→独立选择 | 女主争取工作机会，面对真实能力缺口主动补课 |
| suspense | 公平线索揭开谜题；异常→假设→查证→重释→真相后果 | 检验一份矛盾记录，旧物证改变对嫌疑人的判断 |
| crime | 事实、程序与责任；调查→证据链受挑战→核验→责任落地 | 核验证言来源，避免把传闻当成证据 |
| comedy | 情境错位与回收；预期→偏差→升级→反噬→巧妙回收 | 角色的省事策略反而增加麻烦，最终用先前小道具解决 |
| historical-power | 筹码与联盟；困局→试探→交换→背叛代价→权力选择 | 争取盟友必须放弃另一项利益，对手有合理回应 |
| fantasy | 能力规则中的成长；验证→限制→代价→策略突破→责任 | 用受限制能力完成小任务，奖励引出新的责任 |
| scifi | 核心假设改变人；实验→副作用→规则代价→伦理选择 | 一次记忆交换解决工作问题，却损害一段关系 |
| survival | 资源约束下合作；危险→任务→失误→团队选择→脱险 | 争取有限电力，必须在两个需要之间作选择 |
| youth | 归属与自主成长；愿望→伙伴→认同冲突→失败→承担 | 一次比赛迫使角色在认同与诚实之间作决定 |
| workplace | 专业能力与利益；业务目标→执行→竞争→伦理代价→结果 | 处理真实交付失败，在客户需求和团队能力间协商 |
| period | 时代中的生计与情感；生活任务→机会→牺牲→新秩序 | 一次就业机会改变家里的照护与收入安排 |
| rural | 劳动与共同体；生产任务→信任→试验→合作→可见产出 | 解决一次农产品交付问题，合作而非万能个人救场 |
| culture | 人物任务中的技艺传承；需求→学习→误解→承担→变化 | 主角为修复家人物件学习技艺，重新理解一段关系 |
| action | 空间明确的行动与代价；目标→受限→失误→战术改变→责任 | 护送目标途中失去关键工具，靠合作改变路线 |
| thriller | 未知规则与选择后果；异常→试探→错误→代价→理解 | 为保护伙伴试验一个异常规则，发现其触发条件 |

## 桥段组合

“重生、穿越、系统、马甲、先婚后爱、破镜重圆、复仇、萌宝”作为 tropes，不代替主类型的任务逻辑。重生要确定信息差及其失效代价；系统要有明确能力边界；马甲揭晓前需铺垫；关系桥段要有双方行动；复仇应表现事实、代价与后果，不能用连续羞辱代替人物发展；萌宝不能只作万能和解工具。

混合类型以主类型的终局承诺为轴。例如“悬疑+爱情”中，亲密关系可以增加查证代价，但不能用恋爱结局替代真相；“家庭+喜剧”中笑点要推动家庭处境，不让笑点消解需要承担的责任。辅助类型冲突时优先兑现主类型与用户选择。

## 任务逻辑落地

整剧只保留一条清楚主目标及必要支线。人物目标不等同于作者想让他发生的事：每集要写出人物想取得什么、阻力来自谁/什么、他如何尝试、为何改策略、必须作何选择、后果是什么、兑现了哪项承诺、下一集承接哪种状态。

每集 beat 使用 goal、obstacle、strategy、choice、consequence、payoff、hook；它们在剧本 story 中落地，关键步骤有具体镜头。最后一集的 hook 可写情感余韵或新生活状态，不强行新增未决主谜题。少集数压缩阶段，多集数扩展真实任务链；不靠重复同一打脸/误会/绑架撑集数。

人物规划至少包含 wants（外部目标）、needs（内在认识）、belief（错误或局限认识）、boundary（不愿付出的代价）、agency（会采取的策略）。配角和对手也有自己的目标。伏笔记录引入集、推进证据和回收集；重要谜底不能靠最后新增事实解答。

## 画面、声音与时长

视觉形式可选择原创2D、3D或模型支持的写实影像风格；写实生成不等于真人实拍，不代表已拥有真人演员或拍摄团队。选9:16/16:9等画幅时核验视频模型参数和目标平台规格。固定外形、服装、语气需要提供制作设定，但提示词不能保证模型绝对一致。

镜头时长首先受可用模型能力约束，剧本再以该镜头表分配动作与台词。一镜优先一个说话人，允许反应、环境、行动镜头无台词。普通话每秒3.5字只作规划默认值，不是语音实测；情感戏/喜剧要留停顿，快速台词需要试音，不能为了过检查直接提高语速配置。

单集约30秒时优先一个决策；1–3分钟可安排一个完整小任务及结果；更长单集可用两三个相连场景并分配转折。以上是创作建议，不是保证留存的秒级公式。

## 研究边界

读取 [研究依据](research.md)。已核验资料支持多元题材、人物质感、因果与文化细节的重要性；18类具体框架是编辑归纳，不是从报告得到的统计因果。用户给的三部3D男频样本只用于对应方向，不能外推为所有题材的成功原因。其他题材没有逐集正片数据时如实标B/C级；不生成假的热榜、点赞量或爆款概率。
