# 普通话短剧机制库

## 证据等级

A级：实际可访问的正片/字幕，附集号与时间码，可支持镜头/台词观察。B级：平台简介或主创/官方大会资料，可支持主题/方向，不支持完整逐集结构。C级：编剧经验或原创推断，用于试验，不称作已证实爆款原因。案例 metrics 只报告实测口径；无留存/推荐曝光数据时不能建立因果结论。

已核验的 B 级依据（2026-10-14）：
- [红果创作者大会报道](https://www.cnsa.cn/art/2025/11/27/art_1955_47930.html)：现实与传统文化题材、漫剧发展方向，平台强调剧情逻辑与人物塑造；不等同于每个题材必然爆款。
- [红果《盛夏芬德拉》介绍](https://hongguoduanju.com/detail?series_id=7550544718799588376)：可分析从克制到情感释放的关系发展承诺；未观看全剧，不能据此给逐集结论。
- [编剧创享计划](https://www.cnsa.cn/art/2026/7/24/art_1977_49073.html)：有从剧本到制作转化的合作机制；不能据此声称普通账号自动供片可过审。

下面是 C 级创作操作规则，需用用户样本与制作后的真实观看数据迭代。它们不是从上述三页逐字抽取的规则。

## 从题材到情绪兑现

| 机制 | 操作 | 常见失效 | 验证观察 |
|---|---|---|---|
| 情绪承诺 | 先决定观众期待被理解、关系修复、公平兑现或谜题揭晓 | 只堆身份、富豪、受辱标签 | 关键行动是否兑现承诺 |
| 主动目标 | 主角本集要做一件具体事，并遭到可见阻力 | 主角靠旁人讲解或巧合取胜 | 能否用行动拍出目标 |
| 开场缺口 | 首镜呈现异常/矛盾/即将付出的代价 | 长旁白介绍身世，问题模糊 | 不看简介也知道眼前冲突 |
| 信息差 | 观众和人物掌握不同线索，先种证据 | 突然塞新身份强行反转 | 反转前存在可追溯的线索 |
| 升级与代价 | 行动改变资源/关系/危险，胜利带来新难题 | 重复辱骂/重复打脸，状态不变 | 每场结束与开始状态不同 |
| 情绪兑现 | 一个小承诺得到行动或关系变化的回应 | 无限吊胃口，反复否定结果 | 本集至少有一次明确进展 |
| 集尾悬念 | 主角作选择，暴露后果或新证据 | 黑屏突断、未播台词造悬念 | 下一集承接同一未决问题 |
| 系列闭环 | 伏笔有引入、推进、回收集号 | 越写越多支线，结局失踪 | 每个主伏笔都有回收安排 |
| 现实与文化质感 | 用职业动作、器物、家庭关系表达环境 | 地名装饰、文化符号堆砌 | 删除环境后剧情是否失真 |
| 普通话表演 | 台词有明确对象、意图和可演停顿 | 书面腔解释剧情，滥用网络词 | 配音试听是否自然且能演 |
| 可生产性 | 控角色、场景、动作难度；保持外形与声音 | 大群戏/复杂手部/不停换装 | 样片能否稳定复現 |

一分钟单集可试验“冲突→尝试→阻力→选择→结果/悬念”，但不写死 3 秒/15 秒公式。不同题材让观众追看的理由不同：情感看关系推进，悬疑看证据链，家庭看价值冲突，成长看能力与代价。根据实际集长调整节拍，不机械每五秒反转。

## 导演评估表（主观，非爆款预测）

每项 0–2 分：冲突可见、人物主动、因果清楚、情绪兑现、伏笔可回收、普通话自然、对白能在时长内讲完、镜头可生成、原创性、题材表达可供片。0=缺失/失败，1=需修改，2=具体可执行。任一为 0 时修改对应项；达到总分不代表平台审核通过或商业收益。

## 案例拆解格式

每集记录：episode、timecode、观察、角色目标/障碍、状态变化、线索引入/回收、情绪、对白秒数、集尾未决问题、证据URL。机制归纳另列适用题材、失效条件、替代解释、原创应用。将同一套路的多个样本对照，但不把重复出现当成因果。

运行数据回收时先问口径：首段留存、完播、下一集转化、点赞/有效播放、评论情绪、审核拒绝原因。不同平台数据不能直接相加。修改一个关键变量做样片比较；曝光小或人群不同则标为不可比较。
