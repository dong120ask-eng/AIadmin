# 外部执行协议

记录task_id、店铺ID、对象ID、输入版本、授权范围/有效期、前值、目标值、预算和截止。幂等键用店铺+目标+动作+版本；同对象串行。锁与库存原子操作依赖真实执行器，未实现时标记仅支持人工串行。

状态：planned→prepared→authorized→running→submitted→verified；另有blocked/failed/unknown。已有授权直接引用。submitted仅提交；verified须平台回执或重读；真实业务验收另核订单、曝光、履约与结算。

执行：确认账号→检查前值与有效授权→预览差异→小批执行→重读回执→核对→扩大授权批次。价格、库存、预算、退款、发布、报名、会员消息均受对应限额约束。无授权先产草稿。

超时先查平台结果，unknown不得盲重试。只重试确认无副作用或可幂等动作，限次退避。验证码和风控转人工，异常账号停止；其他无依赖店铺继续。恢复先对账未决动作，前值变更重新评估。

回滚只对可逆且授权动作，先确认现值仍属于本次变更。广告已花费用、已成交订单和已发消息不宣称可回滚。回执包含时间、账号、对象、前后值、状态、平台ID/URL、验证方式、错误与下一步，禁止记录密钥、Cookies和完整买家信息。
