# 商品变更与效果实验

保存商品证据、旧版本、新版本、素材权利、当前审核/前端展示状态和变更原因。明确假设、主指标、利润/退款/合规约束、样本需求、观察窗口、对照、停止与回滚条件。默认单变量；不得用平台保存成功替代审核通过，不得用审核通过替代前端生效，更不得当成交改善。

多平台不同商品各建对象ID，不复用素材ID。预览差异与成本，在已授权范围内小批执行；写入必须携带远端版本条件并由适配器原子核验。人工同期修改导致版本冲突则停止，不覆盖他人变更。

回滚先重读当前版本，只有仍属于本次变更且授权有效才恢复；已发生销量、广告费用和已发消息不能回滚。存在活动/投放/价格同期变化时标混杂，无法排除则输出待验证，不宣布因果。小样本不强行选赢家。

交付实验卡、版本指纹、平台审核/展示回执、利润约束、结果及下一轮行动。

先读references/execution.md，涉及平台政策核当前官方来源及适用类目。缺数据先完成独立工作并列最少补数项。已有有效授权内直接做，缺权限或工具先给可审阅操作包。结果区分已生成、已提交、平台存储值确认、审核通过、展示生效和真实业务结果。
