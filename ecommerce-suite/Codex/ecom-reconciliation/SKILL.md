# 财务对账与结算差异

先核平台、店铺、商品、地区、期间、证据来源、负责人和执行权限。缺数据时标待确认，先完成不依赖缺项的分析和草稿。

## 专项操作

按订单/结算单关联支付、退款、补贴、手续费、广告、物流、采购及发票；明确账期和跨期；差异分时间差、口径差、重复、漏记及真实异常；涉及税务依当前正式来源与会计审核，不伪造税率结论；付款开票须授权。

## 跨环节与执行

读取 references/operations.md 关联上下游；按 references/metrics.md 核口径；外部动作遵循 references/execution.md。已有授权内推进，缺授权先做好可审阅预览。平台与法律规则以当前官方原文核实，无法核实标阻塞；不编造资质、报价、接口或业务结果。

## 交付与验收

输出对账映射、差异清单、应收应付、结算现金预测和凭据缺失项。每项记录事实/假设/待确认、来源、影响、优先级、负责人、依赖、截止、预算、前后值、验收及恢复条件。区分本地生成、提交、平台确认和真实业务验收。未连接系统时只生成操作包，不声称已采购、发货、付款或后台托管。
