# 市场调研与选品

先核平台、店铺、商品、地区、期间、证据来源、负责人和执行权限。缺数据时标待确认，先完成不依赖缺项的分析和草稿。

## 专项操作

逐候选建立需求证据、竞争、差异点、到岸成本、贡献利润情景、资质、供应稳定性、售后负担、现金占用；评分权重由项目确定，未知不补造。先小批测款，定义样本与退出条件，禁止把供应商宣传销量当市场需求。

## 跨环节与执行

读取 references/operations.md 关联上下游；按 references/metrics.md 核口径；外部动作遵循 references/execution.md。已有授权内推进，缺授权先做好可审阅预览。平台与法律规则以当前官方原文核实，无法核实标阻塞；不编造资质、报价、接口或业务结果。

## 交付与验收

输出候选比较、证据矩阵、测款单、淘汰理由与资金上限。每项记录事实/假设/待确认、来源、影响、优先级、负责人、依赖、截止、预算、前后值、验收及恢复条件。区分本地生成、提交、平台确认和真实业务验收。未连接系统时只生成操作包，不声称已采购、发货、付款或后台托管。
