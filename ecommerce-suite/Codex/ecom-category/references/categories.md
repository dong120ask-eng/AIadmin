# 品类适配：风险特征优先

本表为工作线索，非现行法规或平台准入结论。上线前核销售地区、平台、主体及具体商品官方要求，保留生效日期和证据。对未列品类采用最后一行机制。

|品类/特征|必查问题|关联处理|
|---|---|---|
|食品饮料|生产/经营及标签、配料过敏原、保质期、储运、临期、破损污染|资质核查、批次效期、包装测试、召回范围|
|生鲜冷链|温控、损耗、区域可达、签收、时效、腐败争议|区域承诺、冷链记录、异常赔付草案|
|美妆个护|备案/注册适用性、成分、功效证据、敏感与过敏、批次|证据审核、使用说明、异常升级|
|服装鞋包|尺码、版型、色差、材质、洗护、季节、退货|规格表、实测证据、退货原因与周转|
|数码家电|型号兼容、电气安全、适用认证、序列号、保修、安装|兼容矩阵、质检、售后维修与备件|
|家具家居建材|尺寸测量、材质、气味、安装、上楼、破损、大件退运|测量确认、服务覆盖与费用、运输包装|
|母婴儿童玩具|年龄适配、吞咽等安全风险、适用认证、材质|说明证据、安全审核、召回升级|
|药品/器械/保健食品|主体及产品资质、批准宣传、准入、储存、处方等适用限制|专业审核、禁止凭图推功效、特殊销售流程|
|宠物用品/饲料|物种年龄适配、配方、使用风险、批次|标签证据、适配说明与异常记录|
|珠宝奢品/收藏|真伪、材质等级、鉴定、序列、保价|来源凭证、鉴定、物流与争议证据|
|汽车配件/工具|车型型号兼容、安装、安全、尺寸|适配表、安装条件、售后责任|
|农资/化学品/特殊运输|用途许可、危险特性、包装、运输储存|专业准入审核、禁限售与运输核查|
|图书文具/数字内容|版权、版本、授权、交付、激活与退款条件|权利凭证、交付证据与规则核验|
|服务/定制商品|范围、工期、验收、修改次数、履约与退款|需求确认、里程碑与交付记录|
|跨境/进口商品|地区准入、报关税费、标签、时效与退运|销售地区特定审核及凭证|
|其他/混合新品类|是否入口/接触皮肤/儿童使用/电气/危险/有时效/需安装/含知识产权|建立风险档案，叠加相关规则，未知升级专家|
