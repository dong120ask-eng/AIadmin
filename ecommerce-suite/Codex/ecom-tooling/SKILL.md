# 工具插件与连接能力管理

先核平台、店铺、商品、地区、期间、证据来源、负责人和执行权限。缺数据时标待确认，先完成不依赖缺项的分析和草稿。

## 专项操作

读取references/tool-matrix.md，盘点宿主实际暴露工具和已授权账号；每接口记录官方来源、权限、调用限额、费用、输入输出、幂等和错误处理；选第三方服务前核官方资料与当前能力，未安装未验收不标可用；插件发现不等于可操作商家后台。

## 跨环节与执行

读取 references/operations.md 关联上下游；按 references/metrics.md 核口径；外部动作遵循 references/execution.md。已有授权内推进，缺授权先做好可审阅预览。平台与法律规则以当前官方原文核实，无法核实标阻塞；不编造资质、报价、接口或业务结果。

## 交付与验收

输出能力矩阵、适配契约、缺口、接入顺序及真实小任务验收计划。每项记录事实/假设/待确认、来源、影响、优先级、负责人、依赖、截止、预算、前后值、验收及恢复条件。区分本地生成、提交、平台确认和真实业务验收。未连接系统时只生成操作包，不声称已采购、发货、付款或后台托管。
