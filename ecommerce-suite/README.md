## 使用

Codex将Codex目录中的26个完整技能放入项目.agents/skills，或运行`python 安装Codex.py "项目路径"`，同名技能逐文件一致则跳过，存在本地修改则整次拒绝写入；复制失败尝试回滚，升级前备份并检查本地修改。

WorkBuddy使用下载包中WorkBuddy下26个独立ZIP，客户端真实导入待验收。豆包使用豆包目录的总控及专项txt；普通对话不自动获得执行器或店铺权限。

## 能力与验证

6类离线计算/质量工具；单机自动化门控原型；26项技能流程。合成示例只作教学。

36项本地回归测试：5项经营计算、2项容量、22项自动化门控、7项数据质量；不等于真实平台验收。

```bash
python 示例与验收/test_ecom.py
python 示例与验收/test_capacity.py
python 示例与验收/test_automation.py
python 示例与验收/test_data_quality.py
```

尚无七平台专用商家执行器、生产调度和统一预算/库存服务；报名、投放、改价、库存写入仍阻塞。单人经营容量需实测，不承诺无限店铺、销量或利润。
