# 产品分析方法

建立事实账本：fact_id、text、evidence_ref、source_type、verified_at、scope、confidence。source_type用image_visible/user_provided/official_verified/hypothesis，不能用confidence评分代替证据。

分三层卖点：产品事实（成分规格用途）；可证实比较优势（实测、同口径报价或受认可证明）；经营服务差异（渠道、配送、咨询、售后等实际服务）。每项比较写对照对象、口径、时间与限制。包装外语、商标或图标不等于国际认证。

受监管品类先读取真实核准文件并核查当前规范。药品照片不证明真伪；OTC不是零风险，也不证明祛痘、调经、减肥等附加功效。把药品注册、广告审批、平台经营资质分别核查。食品不宣称治病；金融不承诺收益。拒绝未经核实的保证，保留可执行的事实分析。

市场判断用实际样本与统计口径。历史市场数据标注年份、渠道、单位及来源，不能当作当前全渠道数据。没有实际调研时人群只是待验证假设。选题评分是工作优先级，不是爆款概率。
