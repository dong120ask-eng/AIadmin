# 图文制作方法

先确定读者要获得的一个结论，设计封面承诺、页面顺序、逐页信息和结尾。给每页写主标题、正文、画面要求及证据。前页说明价值，后页兑现；一页一个信息重点，不只把长文截成图片。

从当前平台规则确定比例、数量和文件要求；没有核实只给可编辑设计与建议规格。生成图中文字需逐字校验，必要时用排版工具叠字；每页字体层级、留白和人物一致性保持统一。

交付封面文案、逐页文案、实际图片或图像需求、图片顺序、说明、相关标签和真实互动问题。只有实际图片可打开、文字校验通过才标images_ready。保留原始素材及权利记录。

输出assets/output-contract.json所列字段，内容类型用image_text。缺失工具列入limitations，产物哈希与本次版本关联。
