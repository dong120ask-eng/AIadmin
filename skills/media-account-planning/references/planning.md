# 媒体与账号规划

依次回答：希望用户做什么；目标人群为什么在该媒体消费内容；我们已有何种账号与资质；该选题适合何种形式；实际工具能做到什么；结果如何衡量。

研究候选可用公开APP指数、行业报告及用户资料。只在允许范围读取，记录日期与口径；不要绕过登录或付费墙。创作者入口、普通用户投稿、商家专用入口、邀请制或客户端专用入口分别登记。

账号状态用unverified/login_required/verified/blocked。授权登记allowed_platforms、account_external_ids、topic_scope、forms、schedule_window、daily_limit、confirmed_at；缺项不扩权。

混合经营实例：同一真实产品母题可以变成长文解释、图文检查表和视频演示；它们共享事实而不共享全部表达。服务承诺以实际服务为准。每次只增加已核验的渠道，保留单平台运营指标。
