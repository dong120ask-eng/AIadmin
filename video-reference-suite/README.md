# 参考视频原创改编技能套件 1.0.0

先阅读 [员工执行手册](员工执行手册.md)。包含6个流程技能、Codex版本、WorkBuddy版本、豆包对话适配、即梦与即创制作交接及空白任务模板。

## 使用

- Codex：把 codex/skills 的六个目录复制到项目 .agents/skills，启动新会话并调用 $video-reference-adapt。
- WorkBuddy：从技能页导入 workbuddy 下六个独立ZIP；每个ZIP包含一个完整技能目录。实机导入待验收。
- 豆包：粘贴 adapters/豆包启动指令.md，按阶段上传材料；不是原生技能安装声明。
- 即梦/即创：由上述助手输出操作单，本包没有外部生成执行器。

## 交付边界

结构验证不等于实机安装或成片成功。尚无实际视频/产品/人物输入，本次未做真实生成、配音、口型、剪映导出或发布。MIT仅覆盖本套原创代码、规则与空白模板，不授权第三方素材、模型或软件。

AIadmin元数据在本次检查仍为private，不能称为已向公众开源；仓库可见性需另行修改并验证。
