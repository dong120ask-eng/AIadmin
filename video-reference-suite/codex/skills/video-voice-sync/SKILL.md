# 配音与口型制作

1. 读取 references/handoff.md，核对最终台词、人物与声音使用范围。优先本人录音或平台许可音色，不模仿参考视频里无授权的真人声音。
2. 将台词按镜头分句，标读音、停顿、重音、目标时间窗；实际录制后回填时长，过长先改台词。
3. 区分换音色、改台词、口型重制：仅变音色也不能保证同步。没有实际口型工具时选旁白配产品画面或真人重拍。
4. 检查工具支持的人物、语言、音频格式、时长和输入限制，再以定稿音频处理口型。不得用普通图生视频假充精确口型服务。
5. 输出镜头ID、音频准确文件与版本、音频/画面入出点、字幕、口型路线和失败替代。
6. 可实际观看并听取时检查闭口音、句末、静音、转头与面部边缘。不能听/看则标未检，不能宣称通过。改词后回退配音和口型阶段。
