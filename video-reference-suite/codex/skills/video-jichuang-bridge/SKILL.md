# 即创营销视频适配

1. 读取 references/handoff.md 和 references/platform.md，确认是巨量引擎即创而非即梦。
2. 查看实际连接能力。没有真实网页工具就输出人工待办；不虚构登录状态或账号功能。
3. 整理商品名/品牌/型号、卖点证据、人群、使用场景、比例、时长和自有素材，转成当前界面可接收的脚本与字段。
4. 若实际有脚本/成片/数字人入口，记录输入要求、音色与人物使用范围，先制作短样片；当前无入口就改即梦逐镜头或实拍加剪映。
5. 默认重写台词与画面表达，不用原片真人声音或虚假体验，不承诺一键逐镜头复刻。
6. 导出后检查包装文字、动作、主张、声音与字幕。记录真实回执和可读文件，进入video-edit-review。
7. 只授权制作不代表授权广告投放、绑定账号、发布或购买服务。遵守当前任务范围。
