# 逐镜头人物与产品提示词

1. 读取 references/handoff.md，接收已选脚本与镜头表，检查C01人物、P01产品参考图与可用生成能力。
2. 输出人物设定卡、产品核对卡；将品牌文字、规格、包装形状及实际使用方式作为核对项，注明证据图片。
3. 每镜输出：编号、目标时间线、准确输入文件、首帧构图、唯一主要动作、开始/结束状态、相机、光线、音频策略、锁定特征、检查项。
4. 分别写关键帧提示词与图生视频提示词，不把图片提示词当成完整视频指令。负向约束写自然语言，不假设软件有专用负向字段。
5. 先检关键帧再生成视频。生成时长依真实工具支持；输出剪辑裁剪目标，不假定任意秒数均支持。
6. 精确包装采用实拍或合成；复杂拿取、开包、涂抹拆镜或实拍。失败达到已设上限就切换方案。
7. 只在真实文件可读后标generated，并记录实际版本；未接通生成工具则交付提示词和待操作表。
