# 参考视频原创改编总控

1. 读取 references/handoff.md，盘点参考、产品证据、人物与声音素材；整理真实能力表。
2. 能读取视频时逐镜头拆解时间码、景别、运镜、动作、台词作用、节奏；把观察与推测分开。不读取素材就不编造时间码。
3. 输出两版原创脚本，以本产品证据重写主张；说明借鉴结构及重做部分。时长根据实际配音回填。
4. 固定人物C01、产品P01及服装/光线，挑约10秒代表样片；记录单轮预算、重试上限、失败替代路线。
5. 若宿主支持，调用 video-shot-prompts、video-voice-sync、video-edit-review；需要即梦或即创时使用对应bridge技能。不能调用就依其阶段顺序输出员工待办，不要求多智能体。
6. 输出素材索引、缺项、镜头表、新脚本、样片制作表、风险、阶段状态与真实文件路径。保存可独立完成的工作，不因缺一项停掉整条文本准备。
7. 无参考文件时只交付空白表与材料清单；不声称已拆片或已生成。生成工具未接通则停在制作包与待操作状态。
