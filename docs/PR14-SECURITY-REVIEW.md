## 保留且通过自动化检查的机制

SQLite的 `BEGIN IMMEDIATE`、参数化SQL、幂等摘要、租约token、领取排他资源、过期token拒绝更新、unknown保留锁、人工确认旧进程停止后核销，均沿用现有实现。租约为任务超时+60秒，最大540秒；没有租约续命保证，超时/异常不会自动重试。新增按ID领取不会改变其他队列调用默认行为。

费用必须同时有本地任务授权和未知费用授权，未授权不调用适配器。任务内容经stdin交给现有模型，默认模型/提供方及认证保持不变。不添加金额上限承诺；超时、失败和unknown均可能已产生费用。当前没有真实费用金额、费用对账或硬预算控制。
